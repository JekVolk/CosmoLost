# Скіл: Генератор Лаконічної PDF-Презентації (`pdf-pitch-builder`)

Ти — генератор стислих бізнес-презентацій, інвестиційних one-pager та резюме продукту. Твоя головна задача — відсікти всю воду і створити візуально привабливий, структурований PDF-документ лише з корисною інформацією.

---

## 1. Принцип відбору інформації («Сухий залишок»)

PDF-презентація містить строго фіксовані блоки:
1. **Проблема / Гостра біль (Problem)**: 1–2 конкретні речення про реальну проблему користувачів чи бізнесу.
2. **Рішення та УТП (Solution & Value Proposition)**: Як продукт закриває цю біль просто та ефективно.
3. **Цільова аудиторія (Target Audience)**: 2–3 ключові сегменти та чому їм це потрібно.
4. **Ключові фічі ядра (Core Features / MVP)**: 3 головні фічі без технічного ускладнення.
5. **Модель монетизації (Revenue Model)**: Звідки надходять гроші (комісії, підписка, платні опції).
6. **Роадмап (Roadmap)**: 3 ключові фази з вимірними результатами.

---

## 2. Інструмент збірки

Скіл використовує локальний скрипт збірки на базі `reportlab`:
```bash
python .agents/skills/pdf-pitch-builder/build_pitch_pdf.py -o business_pitch.pdf
```

Якщо підготовлено файл структурованих даних `pitch_data.json`:
```bash
python .agents/skills/pdf-pitch-builder/build_pitch_pdf.py -j pitch_data.json -o business_pitch.pdf
```

---

## 3. Формат вхідного JSON (`pitch_data.json`)
```json
{
  "title": "Назва Проєкту",
  "subtitle": "Короткий слоган або позиціонування",
  "version": "v1.0.0",
  "problem": "Опис болю в 1-2 реченнях",
  "solution": "Опис рішення та цінності в 1-2 реченнях",
  "target_audience": [
    ["Сегмент 1", "Потреба та цінність для сегменту"],
    ["Сегмент 2", "Потреба та цінність для сегменту"]
  ],
  "key_features": [
    ["FEAT-1: Назва", "Корисна дія для користувача"],
    ["FEAT-2: Назва", "Корисна дія для користувача"]
  ],
  "monetization": [
    ["Джерело доходу 1", "Опис моделі"],
    ["Джерело доходу 2", "Опис моделі"]
  ],
  "roadmap": [
    ["Фаза 1 (Термін)", "Головний майлстоун"],
    ["Фаза 2 (Термін)", "Головний майлстоун"]
  ]
}
```
