# Інструкція для ШІ-агентів: Робота з Gemini Notebook API

Цей модуль забезпечує інтеграцію робочого простору `business/` з хмарним **Gemini Notebook API** через Model Context Protocol (MCP).

## Роль та Обов'язки ШІ-агента

1. **Синхронізація знань (Knowledge Sync)**:
   - Після будь-яких суттєвих змін у файлах специфікацій (`spec/02_core/`, `spec/04_features/`, `spec/06_architecture/`) агент повинен оновити джерела у блокноті за допомогою інструменту `create_source` або скрипта:
     ```bash
     python .agents/plugins/gemini-notebook/scripts/notebook_manager.py sync-specs --notebook "<NOTEBOOK_ID>"
     ```
2. **Верифікація статусів джерел**:
   - Після завантаження джерел перевіряти їхній статус методом `get_source` (очікуваний фінальний статус: `ACTIVE`).
3. **Генерація презентацій та сценаріїв**:
   - При побудові презентації всі слайди, таймінги, метрики та цитати повинні суворо посилатися на верифіковані джерела з блокнота.
