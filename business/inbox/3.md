## Частина 1. Бізнес-конспект наради (Executive Summary)

### 1. Концепція та тип продукту
Проєкт складається з трьох основних компонентів:
1. **Вебпортал (Web):** Інтерактивна 3D-мапа (Марс, Місяць) із нанесеними точками залишеного чи втраченого космічного обладнання.
2. **Десктопний додаток (Desktop):** Локальна "фабрика контенту" для генерації коротких відео (Shorts) та постів на основі даних із бекенду з використанням AI.
3. **Бекенд та MCP-сервер (Backend & MCP):** Серверна частина на базі Django REST API + інтеграція протоколу MCP (Model Context Protocol) з векторним пошуком (RAG) по базі даних NASA для надання достовірної інформації.
