### [OP-FAC-05] Компіляція та локальний рендеринг ролика (FFmpeg)
* **Цільова сутність**: `ENT-10 PublicationProject`
* **Ініціатор**: `ROLE-Creator` або черга `BatchQueueTask`.
* **Передмови**: `local_audio_path` існує, слайди налаштовані, B-roll фотографії закешовані на локальному диску.
* **Вхідні параметри**: `project_id: string`, `resolution: "1080x1920"`, `fps: 30`, `timeout_sec: int` (зчитується з налаштувань десктопа `config.json`, діапазон 30–300 секунд, дефолт 40с).
* **Дія**:
  1. Переводить статус проєкту в `RENDERING`.
  2. Формує ланцюжок `filter_complex`:
     * Для архівних знімків із нестандартним співвідношенням ($4:3$, квадрат, $800 \times 600$) автоматично застосовує **Blurred Background Pillow-box** (розмитий задній фон із самого зображення + різкий оригінал по центру).
     * Ефект Кена Бернса (`zoompan`), оверлей реактивного PNGTuber, Safe Zones та зведення аудіо (`amix` із нормалізацією EBU R128).
  3. Запускає бінарник FFmpeg через Rust-шар із обгорткою сторожового таймера `tokio::time::timeout(Duration::from_secs(timeout_sec))`.
  4. Адаптивність під слабкі відеокарти: якщо в налаштуваннях встановлено збільшений таймаут (наприклад, 90–120 секунд для вбудованих GPU), процес продовжує спокійно рендерити без передчасного скидання чи зниження якості.
  5. Якщо час рендерингу перевищує встановлений користувачем таймаут (дійсне зависання або аварійний збій кодека):
     * Примусово завершує процес FFmpeg через `child.kill()`.
     * Видаляє пошкоджений або незавершений файл `.mp4`.
     * Встановлює статус `FAILED` із кодом помилки `ERR_RENDER_TIMEOUT_EXCEEDED`.
     * Сигналізує черзі перейти до обробки наступного відео.
* **Післямови**:
  * У разі успіху: статус `RENDERED`, збережено `local_video_path`.
  * У разі збою або таймауту: статус `FAILED` із записом тексту помилки у лог.
* **Хуки**: `HOOK-FAC-03`: Сповіщення UI про результат рендерингу (Toast у Chakra UI).

### [OP-FAC-07] Генерація рекомендації теми наступного ролика (Smart Next Topic Engine)
* **Цільова сутність**: `ENT-10 PublicationProject`
* **Ініціатор**: `ROLE-Creator`
* **Передмови**: Проєкт збережено, заповнено поле `selection_reason`.
* **Вхідні параметри**: `current_project_id: string`, `rubric_id: enum`.
* **Дія**:
  1. Зчитує `selection_reason` поточного проєкту, його цільовий артефакт та рубрику.
  2. Виконує запит до бази даних PostgreSQL за іншими артефактами чи науковими відкриттями зі схожою проблематикою або контрастним результатом (наприклад: після загибелі Spirit у пісках $\to$ 14-річна витривалість Opportunity або останнє селфі InSight; після посадки Eagle $\to$ залишений прапор чи сейсмометр ALSEP).
  3. Формує рекомендацію наступної теми:
     * `next_suggested_artifact_id`: ідентифікатор рекомендованого апарата.
     * `next_suggested_hook`: 3-секундний вступний гачок для серійності.
     * `narrative_bridge`: пояснення сюжетного зв'язку між роликами.
     * `debate_prompt`: дискусійне питання для закріпленого коментаря.
  4. Зберігає рекомендацію у полях `next_suggested_artifact_id` та `next_suggested_hook`.
* **Післямови**: Рекомендована тема відображається у UI, креатор може в 1 клік створити наступний пов'язаний проєкт.
* **Хуки**: Відсутні.

### [OP-PUB-05] Відкриття системної папки з виділеним файлом відео
* **Цільова сутність**: `ENT-14 PublicationDispatch`
* **Ініціатор**: `ROLE-Creator` (кнопка «Відкрити папку з відео» або вибір ручного режиму TikTok / Reels).
* **Передмови**: Файл `local_video_path` фізично існує на диску.

* **Дія**:
  1. Викликає системну команду ОС через `tauri-plugin-shell` / `tauri-plugin-opener`:
