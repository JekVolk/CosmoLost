## 1. Опис фічі
Детальна сторінка артефакту (`/artifacts/:id/`) є ключовим освітнім центром платформи CosmoLost. Вона перетворює сухі архіви та каталоги NASA на захоплюючий сторітелінг («Щоденник останнього Сола»), поєднуючи прямий 3D-перегляд інженерних моделей, інтерактивну науку для школярів та верифіковані академічні посилання на першоджерела NASA.

---

## 2. Структура Контенту: Пріоритети та Інвентар Даних

### 2.1. Контент першої черги (Пріоритет 1: Ядро MVP)
Цей контент відображається обов'язково для кожного артефакту з каталогу:

1. **Паспортна ідентифікація апарата (Header / Identity Block)**:
   * Офіційна назва: наприклад, *Opportunity Rover (MER-B)* або *Apollo 11 Lunar Module Descent Stage (Eagle)*.
   * Материнська місія та агентство: *NASA / JPL-Caltech*, *NASA Apollo Program*.
   * Офіційний архівний код NASA: **NSSDCA ID** (наприклад, `1969-059C`, `2003-027A`).
   * Бейдж небесного тіла та геодезичні координати: Місяць/Марс, широта, довгота, назва кратера чи рівнини (*Perseverance Valley*, *Mare Tranquillitatis*).
   * Операційний статус:
     * `DORMANT` (Вимкнений через розрядження/пил),
     * `PASSIVE_ACTIVE` (Працює пасивно без живлення — місячні лазерні ретрорефлектори LRRR),
     * `DESTROYED_ON_IMPACT` (Навмисно розбитий ступінь Saturn V S-IVB для вивчення місяцетрусів).
   * Дата посадки та дата останнього сеансу зв'язку (Sol contact).

2. **Інтерактивний 3D-в'ювер моделі (Zero-Budget Three.js Streaming)**:
   * Візуалізація інженерної моделі `.glb` через Three.js `GLTFLoader` з керуванням `OrbitControls` (обертання на 360°, зум деталей).
   * **Прямий стрімінг з NASA GitHub CDN**: файл `.glb` завантажується клієнтським браузером напряму з відкритого репозиторію NASA 3D Resources (`raw.githubusercontent.com/nasa/NASA-3D-Resources/...`) без навантаження на власний сервер.

3. **Блок художнього сторітелінгу («Щоденник останнього Сола»)**:
   * **Монолог від першої особи**: 3–4 концентровані атмосферні речення від імені самої машини (опис тиші, вітру, шару марсіанського пилу на сонячних батареях або погляду на Землю з місячного кратера).
   * **Хронологія фінального дня**: фізична причина «замовкання» (наприклад, пилова буря Sol 5111 ровера Opportunity або злам лопаті Ingenuity на 72-му польоті).

4. **Інженерія та Наукова спадщина («Як це працювало»)**:
   * **Пояснення для школярів**: проста земна аналогія принципу дії головного інструменту (наприклад, як спектрометр Mössbauer «просвічував залізо» або як куточкові призми LRRR повертають лазерний промінь точно на Землю).
   * **Наукове відкриття**: головний прорив людства завдяки цьому апарату (доказ рідкої води через мінеральні кульки «Blueberries», фіксація марсотрусів, точне вимірювання відстані до Місяця з точністю до міліметра).

5. **Офіційні шлюзи до першоджерел NASA (NASA Verified Gateways)**:
   * Пряме посилання на архів **NASA Planetary Data System (PDS)**.
   * Пряме посилання на каталог місії **NASA NSSDCA Master Catalog**.
   * Прямий лінк на інтерактивне місце посадки в **NASA Solar System Treks** (з попереднім центруванням камери за координатами).
   * Прямі посилання на знімки в **NASA Image and Video Library** за офіційними кодами PIA (наприклад, `PIA22521`).
   * Офіційні кредити та правовий статус: *"Data and imagery provided by NASA / JPL-Caltech / ASU / USGS. Public Domain."*.

### 2.2. Запланований розширений контент (Пріоритет 2: `[AI-DRAFT] PLANNED` / `<<extend>>`)
Ці функції деталізують історію артефакту на основі глибинних даних з `Ресурси та API для космічного челенджу.md`, але не блокують запуск MVP:

1. **Покроковий трек пересування ровера (MMGIS GeoJSON Traverse Path)**:
   * Відображення повної векторної лінії маршруту ровера або польотів гелікоптера (GeoJSON LineString) з точками ключових зупинок (Waypoints).
   * Джерела: відкриті шари JPL MMGIS (`mars.nasa.gov/mmgis-maps/M20/Layers/json/`) та PDS Analyst's Notebook.
   * Можливість кліку на зупинку із переглядом події цього Сола (Sol 400: знахідка метеорита Heat Shield Rock).

2. **Інтерактивний таймлайн енергетичного згасання (Fade-out Timeline)**:
   * Слайдер часу від першого дня до фінального Сола.
   * Візуалізація падіння виробітку енергії сонячними батареями ($Wh$) та зростання запиленості атмосфери ($Tau$). При зміщенні повзунка 3D-сцена навколо апарата поступово темніє до повної імли.

3. **Фізична орієнтація та нахил корпусу (Rover Pitch & Roll)**:
   * Візуалізація 3D-моделі у реальному положенні останнього дня: наприклад, нахил Spirit у піщаній пастці *Troy* (-11.5°), через який батареї не змогли вловити зимове марсіанське сонце.

4. **Аудіоплеєр «Голоси привидів» (Martian Wind & Quakes Audio)**:
   * Відтворення реальних звуків марсіанського вітру та переведених у чутний діапазон марсотрусів, записаних сейсмометром SEIS модуля InSight.
   * Архівні радіопереговори астронавтів місій Apollo під час паркування місячного багі LRV востаннє.

5. **Порівняльна машина часу: Останнє селфі vs Орбітальний знімок**:
   * Спліт-слайдер «Тоді і зараз»: останнє запилене фото апарата з поверхні поряд зі знімком надвисокої роздільності з орбітального зонда LROC NAC (Місяць) або MRO HiRISE (Марс) через 10–15 років.

6. **Спеціальні історичні локації**:
   * *Three Forks Sample Depot*: 3D-розкладка 10 титанових пробірок Perseverance, залишених на поверхні Марса.
   * *Apollo S-IVB Impact Stages*: кратери від навмисно розбитих третіх ступенів ракет Saturn V для вивчення будови надр Місяця.
   * *Ingenuity Valley of Valinor*: 3D-панорама місця вимушеної стоянки першого позаземного гелікоптера зі зламаною лопаттю.

7. **Аудіоподкасти місій**:
   * Озвучені діалоги про завершення місії (офіційно переведено в беклог `[AI-DRAFT] PLANNED`).

## 3. Атомарні бізнес-вимоги (`REQ-*`)

* **`REQ-ART-01`**: Кожен артефакт має постійну унікальну URL-адресу виду `/artifacts/{slug}/`, що дозволяє пряме посилання з описів роликів у TikTok, YouTube Shorts та Telegram.
* **`REQ-ART-02`**: Блок заголовка відображає офіційну назву, материнську місію, NSSDCA ID, планету, статус та географічні координати.
* **`REQ-ART-03`**: Інтерактивний 3D-в'ювер на Three.js транслює `.glb` модель напряму з відкритих серверів NASA GitHub без посередників.
* **`REQ-ART-04`**: Блок сторітелінгу містить монолог від першої особи та точну хронологію виходу з ладу за архівами NASA.
* **`REQ-ART-05`**: Блок наукової спадщини подає відкриття у форматі «Як це працювало» (для школярів) та науковий факт з PDS.
* **`REQ-ART-06`**: Медіагалерея підвантажує останній кадр та орбітальне фото LROC/HiRISE через прямі URL NASA Image API.
* **`REQ-ART-07`**: Обов'язковий блок верифікованих посилань (NASA Gateways) містить прямі лінки на PDS, NSSDCA, NASA Treks та копірайт-примітку.
* **`REQ-ART-08`**: Кнопка «Копіювати посилання та цитату» записує в буфер обміну готове бібліографічне посилання для шкільних досліджень.
