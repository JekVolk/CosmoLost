# Пропозиція для команди: Гейміфікація CosmoLost (One-Pager для Sign-off)

> **Статус**: `READY FOR REVIEW & SIGN-OFF`  
> **Мета**: Швидке ознайомлення команди з новим функціоналом (Core Loop, контейнери, PvP/PvE дуелі, 3D Тераріум) та отримання фінального «ДОБРО» на запуск розробки.  
> **Час читання**: 3–5 хвилин.

---

## 1. Навіщо це проекту? (Problem vs Solution)

| Було (Проблема) | Стає (Рішення) |
| :--- | :--- |
| **Низький ретеншн**: користувач зайшов на 3D карту NASA, подивився 2 марсоходи і пішов назавжди. | **Щоденний Core Loop**: контейнери накопичуються кожні 4 год (до 10 шт), повертаючи гравця щодня. |
| **Сухі наукові дані**: довгі нудні тексти PDS каталогів ніхто не читає. | **Дедуктивний азарт**: гравець у швидких 30-секундних дуелях (як у GeoGuessr) сам розгадує таємниці місій за реальними фото та графіками телеметрії. |
| **Немає віральності**: немає мотивації ділитися посиланням. | **Публічний 3D Тераріум та Вітрина Куратора**: колекція знайдених артефактів на персональній 3D планеті у профілі (`/profile/:callsign`). |

---

## 2. Як це працює за 30 секунд (Core Loop)

```
   1. ВХІД & СКРИНЬКИ          2. ДЕДУКТИВНИЙ БІЙ (PvP/Bot)        3. НАГОРОДА & КОЛЕКЦІЯ
+-----------------------+     +----------------------------+     +-------------------------+
| За щоденний вхід або  |     | 3 раунди по 30 сек:        |     | Відкриття контейнера:   |
| таймер (кожні 4 год)  | --> | • AstroGuessr (панорама)   | --> | • 1 з 7 рідкостей       |
| нараховуються зачинені|     | • ForensicSol (графіки)    |     | • Дублікат -> RP валюта |
| скриньки (до 10 шт).  |     | • MissionHangar (склади)   |     | • Виставка на 3D планеті|
+-----------------------+     +----------------------------+     +-------------------------+
```

1. **Зберігання**: Контейнери накопичуються автоматично (без агресивного згоряння).
2. **Матчмейкінг**: Пошук реального суперника триває до 8 секунд. Якщо нікого немає — підключається `SpaceBot`, налаштований під точний ELO рейтинг гравця.
3. **Чесна гра (Zero-Knowledge)**: Сервер ніколи не відправляє правильну відповідь на клієнт до моменту вибору — чіти через DevTools неможливі.
4. **Захист від розчарування (Pity System)**:
   * Перші 5 матчів — захист ELO від падіння.
   * На 61-му відкритті гарантовано випадає легендарний `Historic` артефакт.

---

## 3. Чому це вигідно розробляти вже зараз?

1. **База даних уже готова на 100%**:
   * У `backend/core` вже завантажено всі **118 реальних артефактів NASA** (82 на Місяці, 36 на Марсі) з координатами, фотографіями, монологами та телеметрією. Нам не потрібно наповнювати контент вручну!
2. **Нульовий оверхед інфраструктури**:
   * Бекенд будується як ізольований Django-модуль `game` поверх поточної архітектури.
   * Web-клієнт розгортається на чистому FSD v2.1 + Chakra UI v3 без конфліктів із десктопом.
3. **Гнучкий план запуску (MVP за 3 тижні)**:
   * **Фаза 1 (MVP)**: 3 міні-гри (AstroGuessr, ForensicSol, MissionHangar), бот, відкриття скриньок, базовий профіль.
   * **Фаза 2**: 3D Планетарний тераріум, публічний лідерборд, розширення до 9 міні-ігор.

## 4. Розподіл навантаження на команду

| Роль | Основні задачі | Термін |
| :--- | :--- | :---: |
| **Junior Backend** | Моделі `game`, seed-скрипт, Unfold Admin, ELO сервіс, юніт-тести | 5–6 днів |
| **Middle Backend** | Django Channels WS, Redis Matchmaker, Pity лут-система, Google OAuth + JWT | 7–9 днів |
| **Middle Frontend** | FSD v2.1 структура, Zustand WS State Machine, 3 міні-гри, екран Арени, 3D сцена | 10–12 днів |
| **QA / Тестування** | Валідація формули Haversine, Pity симуляція 10 000 дропів, reconnect тест | 3–4 дні |
