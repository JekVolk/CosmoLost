## 1. Опис фічі
Десктопний застосунок «Фабрика контенту» — це автоматизований конвеєр виробництва вірусних науково-популярних коротких відео (Shorts / Reels / TikTok) та постів. Ядром редактора є **візуальний нодовий граф на базі `@xyflow/react` (React Flow)** у зв'язці з дизайн-системою **Chakra UI**.

Конвеєр бере верифіковані дані артефактів через **Редактор API**, формує динамічне слайд-шоу за SMM-шаблонами рубрик, синтезує аудіо з видаленням пауз (Jump-cut), накладає реактивного **PNGTuber-аватара** з ліпсинком, додає Sci-Fi HUD телеметрію та монтує ролик 1080x1920 за допомогою локального FFmpeg sidecar.

Крім візуального режиму, застосунок містить **Native Desktop MCP**, що дозволяє локальним ШІ-агентам (`USER Agents`) автономно запускати генерацію роликів через код.

## 1.1. Фундаментальний закон «Local-First / Клієнтська автономія» та Централізоване зберігання текстів
* **Усі розрахунки та монтаж — на машині користувача**: Увесь процес обробки аудіо (Edge-TTS, Jump-cut фільтрація тиші, RMS-ліпсинк), створення анімацій Кена Бернса, накладання аватара та важкий рендеринг FFmpeg виконуються **строго локально** на обладнанні креатора.
* **Нульове медіа-навантаження на сервер**: Центральний бекенд не отримує, не конвертує і не зберігає важкі відеофайли чи B-roll матеріали (бюджет хостингу $0/міс).
* **Централізоване збереження всіх текстових даних на сервері**: Текст займає мізерний обсяг у PostgreSQL (кілька мегабайтів на тисячі проєктів). Тому **весь текст зберігається та синхронізується на сервері**:
  * Тексти сценаріїв слайдів, монолог диктора, текстові промпти.
  * Згенерований 3-рядковий SEO-опис та перший закріплений коментар (Pin Comment).
  * Персональні збереження проєктів, чернетки, історія ревізій.
  * **Причина вибору даних (`selection_reason`)**: фіксація того, чому саме цей артефакт або науковий факт обрано автором для ролика.
* **Обов'язкове локальне кешування B-roll та 3D**: Усі фотографії високої роздільності з каталогів NASA та 3D-моделі `.glb` десктопний клієнт завантажує напряму з відкритих серверів NASA і зберігає у локальній папці проєкту на диску (`%APPDATA%/CosmoLost/projects/{id}/assets/`), забезпечуючи стабільний офлайн-рендеринг без ризику мережевих збоїв під час роботи FFmpeg.

## 2. Архітектура Нодового Графа (`@xyflow/react`)

Кожен проєкт відеоролика у десктопі представляється у вигляді орієнтованого графа зв'язків (Node Graph Pipeline):

```
+--------------------+      +--------------------+      +--------------------+
| ArtifactSourceNode | ---> | ScriptTemplateNode | ---> |   AudioTTSNode     |
| [Редактор API]     |      | [3-фазний таймлайн]|      | [Edge-TTS + JumpCut|
+--------------------+      +--------------------+      +--------------------+
                                                                  |
                                                                  v
+--------------------+      +--------------------+      +--------------------+
| SocialPublishNode  | <--- |  FFmpegRenderNode  | <--- | VisualCompositeNode|
| [Shorts/TG/Manual] |      | [filter_complex]   |      | [SafeZones+PNGTuber|
+--------------------+      +--------------------+      +--------------------+
```

### 2.1. Специфікація типів нод:
1. **`ArtifactSourceNode` (Вхідна нода)**:
   * Вибір небесного тіла (Місяць / Марс) та пошук артефакту через Редактор API.
   * Вихідні сокети: `metadata`, `photos[]`, `discoveries[]`, `telemetry`.
2. **`ScriptTemplateNode` (Нода рубрики та сценарію)**:
   * Вибір рубрики: «Останній сол», «Як це працює», «Таємниці Місяця», «Краш-тест», «Build in public».
   * **Цільовий хронометраж**: стандартна тривалість ролика становить **~40 секунд** (найбільш вірусний формат для YouTube Shorts / TikTok), із допустимим діапазоном від 15 до 60 секунд.
   * **Динамічний таймлайн $N$ слайдів**: підтримка довільної кількості слайдів $N$ (від 3 до 8) із сумарною тривалістю $15 \le \sum duration \le 60$ секунд.
   * **Причина вибору даних (`selection_reason`)**: обов'язкове поле персонального збереження проєкту (чому автор обрав саме цей апарат чи подію: річниця, трагедія бурі, унікальний прилад, паралель із місією Artemis).
   * Автоматичне компонування: Хук (0–3с) $\to$ $N-2$ B-roll наукових тез (3–32с) $\to$ Seamless Loop CTA (32–40с).
3. **`AudioTTSNode` (Нода синтезу мови та аудіодизайну)**:
   * Вибір мови (UK/EN) та нейронного голосу (`uk-UA-OstapNeural`, `en-US-GuyNeural`).
   * Автоприскорення темпу 1.1x та обрізка тиші (Jump-cut) між фразами ($< 0.15$с).
   * Вихідний аудіопотік: `voice_stream`, `rms_amplitude[]` (для ліпсингу аватара).
4. **`VisualCompositeNode` (Нода композитингу та безпечних зон)**:
   * **Direct NASA CDN Streaming & Local Cache**: фотографії та медіафайли підтягуються для монтажу напряму з відкритих серверів NASA безкоштовно та обов'язково кешуються у локальній папці `%APPDATA%/CosmoLost/projects/{id}/assets/`.
   * **Blurred Background Pillow-box (Обробка архівних знімків)**: для історичних фотографій NASA з пропорціями $4:3$, квадрат чи $800 \times 600$ (Surveyor, Apollo, Viking) система автоматично генерує естетичний розмитий задній фон із самого зображення, розміщуючи різкий оригінал по центру без спотворення та агресивного обрізання.
   * **Safe Zones Overlay**: інтерактивне візуальне підсвічування верхньої (220 px), нижньої (420 px) та правої (150 px) мертвих зон у Canvas-прев'ю.
   * **Ефект Кена Бернса (Ken Burns / zoompan)**: плавний наїзд/від'їзд камери на архівних фотографіях NASA.
   * **PNGTuber модуль (Дефолтний та кастомний аватар)**:
     * *Дефолтний сет*: додаток постачається з готовим фірмовим космічним аватаром від дизайнера Віолетти (4 стани $\times$ 2 фази рота = 8 PNG-спрайтів).
     * *Кастомний імпорт*: користувач має інтерфейс ручного завантаження власних PNG-зображень для будь-якого стану (Custom Avatar Uploader).
     * *Ліпсінк*: анімація відкриття рота перемикається автоматично за RMS-амплітудою звукової доріжки.
   * **Sci-Fi HUD Телеметрія**: напівпрозорий блок координат, заряду та рівня пилу.
   * **Фонова музика**: вибір треку з локальної бібліотеки (Synthwave, Dark Synth, Lo-Fi) або імпорт власного аудіофайлу з автоматичним зведенням на рівні -24 dB.
5. **`SubtitleNode` (Нода кінетичної типографіки)**:
   * Генерація файлу субтитрів `.ass` / `.srt`.
   * Відображення по 2–4 слова з неоновим кольоровим виділенням поточного слова (`#FFD700`).
6. **`FFmpegRenderNode` (Нода компіляції, рендерингу та сторожового таймера)**:
   * Трансляція параметрів графа у команду `ffmpeg -filter_complex`.
   * **Налаштовуваний Rust Watchdog під потужність GPU (Налаштування `render_timeout_sec`)**:
     * На слабких або інтегрованих відеокартах (Intel UHD / Iris, AMD Vega, старі ноутбуки) рендеринг вертикального відео може тривати довше звичайного. Процес **не повинен завчасно вбиватися чи видаляти готовий результат**, якщо він продовжує прогресувати!
     * Таймаут сторожового таймера винесено в налаштування програми: повзунок **`render_timeout_sec`** (діапазон 30–300 секунд).
     * Рекомендовані налаштування: **40 секунд** для дискретних GPU (NVIDIA RTX / Apple Silicon), **90–120 секунд** для бюджетних CPU / інтегрованих карт.
     * Якщо час рендерингу перевищує встановлений ліміт (зависання або краш кодека) — спрацьовує `tokio::time::timeout` та надсилається сигнал `child.kill()`, тимчасові чанки очищуються, а статус переводиться у `FAILED` без блокування черги.
   * Рендеринг вертикального відео 1080x1920 H.264 / AAC.

## 4. Розумний генератор теми наступного ролика (Smart Next Topic Engine)

* **`REQ-FAC-13` (Підбір наступної теми на основі контексту)**:
  * Десктопний редактор містить кнопку **«Придумати тему для наступного відоса»** (`suggest_next_video_topic`).
  * **Алгоритм підбору теми**:
    1. Аналізує обрану рубрику (`ContentTemplate`) та поточний артефакт.
    2. Враховує збережену **причину вибору даних (`selection_reason`)** (наприклад, якщо автор обрав тему загибелі сонячних батарей Spirit у пісках, алгоритм шукає споріднені драматичні або контрастні події).
    3. Виконує семантичний запит до бази даних PostgreSQL за іншими артефактами, приладами чи відкриттями (`ARTIFACTS`, `SCIENTIFIC_DISCOVERIES`, `TELEMETRY`), які ще не були покриті роликами автора.
    4. Генерує готову зв'язку для серійності контенту:
       * **Рекомендований артефакт**: назва та ID у базі.
       * **Сюжетний хук (3 секунди)**: інтригуючий вступний рядок («А ви знали, що брат Opportunity пережив зовсім іншу долю?..»).
       * **Міст-перехід (Narrative Bridge)**: чому глядачеві цікаво подивитися це відео відразу після попереднього.
       * **Промпт для Pin Comment**: дискусійне питання для зв'язування аудиторії в коментарях.
7. **`SocialPublishNode` (Нода дистрибуції)**:
   * Генерація 3-рядкового опису (Байт + SEO + Хештеги) та тексту закріпленого коментаря (Pin Comment).
   * Вибір методу відправки: YouTube Shorts API, Telegram Bot API, TikTok або папка на диску.

## 3. Специфікація генератора слайд-шоу через FFmpeg

Слайд-шоу та відеоряд монтуються нативно за допомогою наступної структури `filter_complex`:

```bash
ffmpeg -loop 1 -t 3 -i slide1_hook.jpg \
       -loop 1 -t 12 -i slide2_broll.jpg \
       -loop 1 -t 15 -i slide3_drama.jpg \
       -loop 1 -t 5 -i slide4_loop.jpg \
       -i voice_jumpcut.mp3 -i synthwave_bg.mp3 -i avatar_spritesheet.png \
       -filter_complex "\
         [0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,zoompan=z='min(zoom+0.0015,1.2)':d=90:x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':s=1080x1920[v0]; \
         [1:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,zoompan=z='min(zoom+0.001,1.15)':d=360:x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':s=1080x1920[v1]; \
         [v0][v1]xfade=transition=fade:duration=0.5:offset=2.5[v01]; \
         ... \
         [amix_out]volume=-24dB[bg]; \
         [4:a]volume=-3dB[voice]; \
         [voice][bg]amix=inputs=2:duration=first[aout]" \
       -c:v libx264 -preset fast -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k output.mp4
```

## 4. Пакетний режим генерації (Batch Production Mode)

Згідно з висновками дослідження `MKT-01`, автори не повинні створювати по одному відео.
* **`REQ-FAC-11` (Batch Queue)**: Десктопний редактор підтримує пакетну генерацію: користувач обирає 5 артефактів та натискає **«Згенерувати пакет із 5 роликів»**.
* Черга фоново проганяє нодові графи та зберігає 5 готових файлів `.mp4` з відповідними описами у вихідну папку, заощаджуючи час креатора.
