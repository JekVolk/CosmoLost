# Єдиний Словник Понять та Термінів (02_GLOSSARY.md)

> **Статус**: `APPROVED`  
> **Версія специфікації**: `v0.3.0`  
> **Принцип**: Ubiquitous Language (DDD). Заборонено використання синонімів та неоднозначних трактувань.

## Реєстр термінів системи CosmoLost

| ID | Українська назва | Міжнародна назва (English) | Семантичне визначення | Де використовується |
| :--- | :--- | :--- | :--- | :--- |
| **`TERM-01`** | **Покинутий артефакт** | **Abandoned Artifact / Hardware** | Будь-який рукотворний космічний апарат або його частина (ровер, лендер, ступінь ракети, дзеркало, датчик, пробірка), що знаходиться на поверхні або орбіті небесного тіла після завершення чи зупинки місії. | [`ENT-Artifact`](../05_domain/01_ENTITIES.md), Вебпортал, Десктоп |
| **`TERM-02`** | **Небесне тіло** | **Celestial Body** | Планета, супутник або координатна сцена (Місяць, Марс, глибокий космос), на поверхні якої розміщені артефакти та розгортається карта. | [`ENT-CelestialBody`](../05_domain/01_ENTITIES.md), Вебпортал |
| **`TERM-03`** | **Космічна місія** | **Space Mission** | Офіційна наукова експедиція (наприклад, Apollo 11, Mars 2020), в межах якої один або декілька артефактів було доставлено у космос. | [`ENT-Mission`](../05_domain/01_ENTITIES.md), API, Адмінка |
| **`TERM-04`** | **Сол** | **Sol** | Марсіанська доба (триває приблизно 24 години 39 хвилин 35 секунд). Використовується для відліку часу життя марсіанських апаратів. | [`ENT-TraverseWaypoint`](../05_domain/01_ENTITIES.md), Телеметрія |
| **`TERM-05`** | **Останній Сол** | **Last Sol** | Останній марсіанський день, протягом якого апарат виходив на зв'язок або передав фінальний пакет телеметрії/фотографію перед виходом з ладу. | Сторітелінг, Сценарії відео |
| **`TERM-06`** | **Точка зупинки маршруту** | **Traverse Waypoint** | Векторна точка на поверхні планети з координатами $(lat, lon, elevation)$, що фіксує зупинку ровера, посадку або скидання обладнання. | [`ENT-TraverseWaypoint`](../05_domain/01_ENTITIES.md), MMGIS |
| **`TERM-07`** | **Фабрика контенту** | **Content Factory** | Десктопний нативний застосунок на базі Tauri + Chakra UI для автоматизованого монтажу коротких відео (Shorts/Reels) та публікації постів. | [`FEAT-03`](../04_features/FEAT-03_content_factory.md), [`ROLE-Creator`](../03_users/01_ROLES.md) |
| **`TERM-08`** | **Серверний Шлюз MCP** | **Server Model Context Protocol** | Серверний інтерфейс FastMCP на бекенді Django, через який сторонні ШІ-агенти (Gemini, Claude) читають верифіковану базу знань NASA. | [`FEAT-05`](../04_features/FEAT-05_mcp_rag_gateway.md), API |
| **`TERM-09`** | **Нативний Десктопний MCP** | **Native Desktop MCP** | Вбудований у додаток Tauri локальний MCP-сервер, через який локальні ШІ-агенти можуть автономно керувати монтажем та публікацією відео на ПК. | [`FEAT-03`](../04_features/FEAT-03_content_factory.md), C4 діаграма |
| **`TERM-10`** | **Хук уваги** | **Attention Hook** | Перші 1.5–3 секунди вертикального відеоролика (текст, відеоряд, аватар, SFX whoosh), призначені для утримання глядача від прогортання стрічки. | Десктоп, Сценарії відео |
| **`TERM-11`** | **Рубрика контенту** | **Content Pillar / Rubric** | Повторюваний тематичний формат блогу з фіксованою структурою (наприклад, «Останній день на зв'язку», «Словник на пальцях»). | [`ENT-ContentTemplate`](../05_domain/01_ENTITIES.md), Десктоп |
| **`TERM-12`** | **Наукове відкриття** | **Scientific Discovery** | Конкретний науковий факт, підтверджений приладом артефакту (наприклад, виявлення марсотрусів, доказ водяного минулого, лазерне дальномірство). | [`ENT-ScientificDiscovery`](../05_domain/01_ENTITIES.md) |
| **`TERM-13`** | **Безпечні зони** | **Safe Zones** | Розмітка екрана 1080x1920 із відступами зверху (220 px), знизу (420 px) та справа (150 px) для захисту субтитрів та 3D-моделей від перекриття інтерфейсом соцмереж. | [`FEAT-03`](../04_features/FEAT-03_content_factory.md), Відеомонтаж |
| **`TERM-14`** | **PNGTuber** | **PNGTuber (State Machine)** | 2D реактивний віртуальний аватар, що змінює 4 фіксовані стани емоцій (Idle, Expert, Shock, Hype) та відкриває рот під амплітуду звуку. | [`FEAT-03`](../04_features/FEAT-03_content_factory.md) |
| **`TERM-15`** | **Кінетична типографіка** | **Kinetic Typography Subtitles** | Динамічні субтитри по 2–4 слова в центрі екрана з кольоровим підсвічуванням поточного слова та чорною обводкою. | [`FEAT-03`](../04_features/FEAT-03_content_factory.md) |
| **`TERM-16`** | **B-roll перебивки** | **B-roll Cutaways** | Зміна планів, архівні фотографії NASA, вибух-схеми та креслення, що з'являються кожні 3–5 секунд для збереження високого ретеншну. | [`FEAT-03`](../04_features/FEAT-03_content_factory.md) |
| **`TERM-17`** | **Jump-cut аудіо** | **Jump-cut Voice Editing** | Автоматичне вирізання пауз довше 0.15 секунди між фразами диктора для створення щільного, динамічного темпоритму розповіді. | [`FEAT-03`](../04_features/FEAT-03_content_factory.md) |
| **`TERM-18`** | **Закріплений коментар** | **Pin Comment (SEO Bait)** | Перший коментар автора з відкритим дискусійним питанням, що провокує обговорення та стимулює повторні перегляди відео на фоні. | [`FEAT-04`](../04_features/FEAT-04_social_publishing.md) |
| **`TERM-19`** | **Редактор API** | **Editor API** | Спеціалізований REST API бекенду Django для зв'язку з десктопним додатком «Фабрика контенту» (`/api/v1/editor/...`). | [`01_C4_SYSTEM_CONTEXT.md`](../06_architecture/01_C4_SYSTEM_CONTEXT.md) |
| **`TERM-20`** | **Portal API** | **Portal API** | Публічний високопродуктивний кешований REST API бекенду Django для обслуговування вебпорталу (`/api/v1/portal/...`). | [`01_C4_SYSTEM_CONTEXT.md`](../06_architecture/01_C4_SYSTEM_CONTEXT.md) |
