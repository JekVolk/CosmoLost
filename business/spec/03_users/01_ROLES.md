# Реєстр Ролей Системи CosmoLost (01_ROLES.md)

> **Статус**: `APPROVED`  
> **Версія специфікації**: `v0.2.0`  
> **Стандарт**: RBAC (Role-Based Access Control)

---

## 1. Реєстр системних ролей

### [ROLE-01] Анонімний відвідувач вебпорталу (`ROLE-WebUser`)
* **Опис**: Будь-який користувач мережі Інтернет (школяр, студент, аматор астрономії), який перейшов за прямим посиланням із соцмережі або відвідав головний домен.
* **Автентифікація**: Відсутня. Доступ повністю відкритий без реєстрації та паролів.
* **Ключові сценарії**:
  * Обертання інтерактивної 3D-мапи (Місяць/Марс).
  * Фільтрація артефактів за типом, роками та статусом.
  * Перегляд детальної сторінки конкретного артефакту (`/artifacts/:id`) з 3D-моделями `.glb`, фотографіями та історією.
  * Прослуховування аудіоподкасту на сторінці (якщо згенеровано).
  * Копіювання посилання на сторінку для шерингу.

---

### [ROLE-02] Контент-креатор десктопного додатку (`ROLE-Creator`)
* **Опис**: Автор науково-популярного контенту або учасник команди розробників, який використовує десктопний додаток «Фабрика контенту» (Tauri).
* **Автентифікація**: Відсутня на сервері. Програма працює локально на машині користувача.
* **Зберігання даних**: Усі персональні токени (YouTube OAuth2, Telegram Bot Token, OpenAI/ElevenLabs API Keys) зберігаються виключно локально у захищеному сховищі ОС.
* **Ключові сценарії**:
  * Вибір артефакту та рубрики для створення відео.
  * Налаштування блоків сценарію, вибір диктора (TTS) та фонової музики.
  * Запуск локальної генерації відео (виклик бінарника FFmpeg через Tauri sidecar).
  * Експорт готового `.mp4` на диск комп'ютера.
  * Публікація в один клік у YouTube Shorts (Data API) або Telegram-канал.
  * Експорт/імпорт локального конфігураційного файлу налаштувань.

---

### [ROLE-03] Адміністратор бекенду (`ROLE-Admin`)
* **Опис**: Відповідальний інженер команди, який контролює цілісність бази даних, актуальність парсингу та роботу API.
* **Автентифікація**: Обов'язкова сесійна авторизація через Django Unfold Admin (`username` + `password`).
* **Ключові сценарії**:
  * Керування довідниками планет, місій та артефактів (CRUD).
  * Примусовий запуск парсерів та імпорту нових каталогів NASA кнопкою в інтерфейсі адмінки.
  * Моніторинг черг фонових задач та логів помилок зовнішніх API NASA.
  * Модерація та ручне збагачення описів артефактів (`is_featured: true`).

---

### [ROLE-04] Зовнішній ШІ-клієнт (`ROLE-AIAgent`)
* **Опис**: Автономний ШІ-агент або LLM-клієнт (Gemini, Claude Desktop, Antigravity, Cursor), підключений до сервера CosmoLost через протокол Model Context Protocol (FastMCP).
* **Автентифікація**: Відкритий доступ для MVP (заплановано видачу токенів з лімітом 10 000 req/month у `[AI-DRAFT]` плані масштабування).
* **Ключові сценарії**:
  * Виклик MCP-інструменту пошуку артефактів за фільтрами (`search_artifacts`).
  * Отримання структурованої картки артефакту з перевіреними науковими фактами (`get_artifact_details`).
  * Отримання верифікованих посилань на першоджерела NASA та сторінки CosmoLost (`get_citations`).
