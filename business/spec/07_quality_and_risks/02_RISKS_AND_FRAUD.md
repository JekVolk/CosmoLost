## 1. Реєстр ризиків проєкту (`RISK-*`)

| ID | Категорія ризику | Опис загрози | Ймовірність / Вплив | Стратегія пом'якшення (Mitigation) |
| :--- | :--- | :--- | :---: | :--- |
| **`RISK-01`** | **Квоти YouTube Data API** | Вичерпання щоденного ліміту (10 000 units = ~6 завантажених відео на день на один Client ID). | Середня / Висока | Кожен користувач десктопу може ввести свій власний Google Cloud API ключ у налаштуваннях; у разі помилки 403 активується fallback — збереження `.mp4` для ручного завантаження. |
| **`RISK-02`** | **Витік приватних токенів** | Компрометація призначених для користувача API-ключів соцмереж або платних сервісів озвучки. | Низька / Критична | Десктопний додаток зберігає ключі виключно локально у системному захищеному сховищі ОС (OS Keychain / Credential Vault) через плагін Tauri; ключі ніколи не передаються на бекенд CosmoLost. |
| **`RISK-03`** | **Авторські права NASA** | Звинувачення у порушенні правил використання матеріалів NASA або фальшиве позиціонування як «офіційного продукту NASA». | Низька / Середня | На всіх сторінках вебпорталу, у титрах згенерованих відео та у відповідях FastMCP додається обов'язковий дисклеймер: *"Data & imagery provided by NASA / JPL-Caltech / ASU. Not an official NASA product"*. |
| **`RISK-04`** | **Недоступність / рейт-ліміти NASA API** | Блокування IP або відмова зовнішніх ендпоінтів `api.nasa.gov` під час демонстрації журі. | Висока / Критична | Бекенд здійснює попередній локальний імпорт і кешування повного каталогу артефактів; під час роботи користувачів прямі запити до зовнішніх серверів NASA не виконуються. |
| **`RISK-05`** | **DoS-атака на FastMCP / REST API** | Перевантаження публічних ендпоінтів бекенду без авторизації. | Середня / Середня | Налаштування Nginx / Cloudflare Rate Limiting (максимум 60 req/min на IP для API та 30 req/min для FastMCP). |
| **`RISK-06`** | **ШІ-галюцинації у відео** | Генерація вигаданих фактів про «інопланетян» чи неіснуючі поломки апаратів. | Середня / Висока | Сценарії відео формуються строго на основі заздалегідь валідованих полів бази даних CosmoLost (`kid_friendly_story`, `scientific_fact`) без вільної генерації тексту моделлю. |
