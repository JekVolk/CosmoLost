## 🗺️ 1. Загальна Карта Сторінок Вебпорталу CosmoLost

Вебпортал містить **5 основних функціональних сторінок**:

```
+-----------------------------------------------------------------------------------------+
| СТОРІНКА 1: ГОЛОВНА — 3D ІНТЕРАКТИВНИЙ ГЛОБУС (/ або /map)                              |
| -> Повнорозмірна сфера Three.js, перемикач Moon/Mars, фільтри, кластеризація <500м      |
+-----------------------------------------------------------------------------------------+
| СТОРІНКА 2: ВИСУВНА КАРТКА АРТЕФАКТУ (/artifacts/:id)                                   |
| -> 3D .glb модель (GLTFLoader), монолог en-US, прилади, відкриття, архівні фото         |
+-----------------------------------------------------------------------------------------+
| СТОРІНКА 3: ДЕТАЛЬНА СТОРІНКА МІСІЇ (/missions/:id)                                     |
| -> Паспорт експедиції NASA, дати, маніфест заліза, відкриття, ролики спільноти          |
+-----------------------------------------------------------------------------------------+
| СТОРІНКА 4: КАТАЛОГ УСІХ АРТЕФАКТІВ ТА МІСІЙ СПИСКОМ (/catalog)                         |
| -> Табличний / сітковий режим для швидкого пошуку без 3D-навантаження                   |
+-----------------------------------------------------------------------------------------+
| СТОРІНКА 5: ВІДЕОГАЛЕРЕЯ СПІЛЬНОТИ (/community)                                         |
| -> Вітрина 9:16 Shorts/TikTok із науковими першоджерелами та форма подачі ролика        |
+-----------------------------------------------------------------------------------------+
```

## 🚀 2. Детальна Анатомія Сторінки Місії (`/missions/:id`)

Коли користувач переходить на сторінку місії (наприклад, **Apollo 11**, **Mars 2020** або **Mars Exploration Rover - Opportunity**), він бачить структуровану історію польоту, розбиту на **6 чітких функціональних блоків**.

```
+-----------------------------------------------------------------------------------+
| БЛОК 1: HERO-ШАПКА МІСІЇ (Назва, агентство, дати, швидка статистика)              |
+-----------------------------------------------------------------------------------+
| БЛОК 2: ІСТОРІЯ ТА НАУКОВА СПАДЩИНА (Опис місії з поля missions.summary)          |
+-----------------------------------------------------------------------------------+
| БЛОК 3: МАНІФЕСТ ЗАЛИШЕНОГО ОБЛАДНАННЯ (Картки всіх апаратів цієї місії)         |
+-----------------------------------------------------------------------------------+
| БЛОК 4: ЗВЕДЕНІ НАУКОВІ ВІДКРИТТЯ МІСІЇ (Прилади, відкриття, факти PDS)         |
+-----------------------------------------------------------------------------------+
| БЛОК 5: РОЛИКИ СПІЛЬНОТИ ПРО ЦЮ МІСІЮ (Shorts/TikTok з цитуванням джерел)        |
+-----------------------------------------------------------------------------------+
| БЛОК 6: ОФІЦІЙНІ РЕФЕРЕНСИ ТА ФУТЕР NASA (Прямий лінк на NSSDCA, авторські права)|
+-----------------------------------------------------------------------------------+
```

### 🟢 БЛОК 1: Hero-Шапка Місії (Mission Header & Key Stats)
Розташований у верхній частині сторінки. Одразу дає зрозуміти масштаби та статус експедиції.

#### Поля блоку та прив'язка до бази даних:
1. **Назва місії (H1)**:
   * *Поле БД*: `missions.name`
   * *Приклад*: `Mars Exploration Rover - Opportunity` або `Apollo 11`
   * *Типографіка*: H1, шрифт `Space Grotesk`, білий колір `#FFFFFF`.
2. **Космічне агентство (Бейдж)**:
   * *Поле БД*: `missions.agency`
   * *Приклад*: `NASA` або `NASA / JPL-Caltech`
   * *Стиль*: Контрастний синій бейдж Chakra UI (`colorPalette="blue"`).
3. **Офіційний каталожний код NASA (Копійований бейдж)**:
   * *Поле БД*: `missions.nssdca_id`
   * *Приклад*: `NSSDC ID: 2003-032A` (для Opportunity) або `1969-059A` (для Apollo 11)
   * *UX*: Кнопка поруч: «Скопіювати ID для наукових робіт».
4. **Небесне тіло призначення (Бейдж з іконкою)**:
   * *Джерело*: Визначається через зв'язані артефакти (`artifacts.celestial_body_id`).
   * *Приклад*: `Марс 🔴` або `Місяць 🌕`.
5. **Плашки швидкої статистики (Grid 4 колонки)**:
   * **Плашка 1 (Старт із Землі)**:
     * *Поле БД*: `missions.launch_date`
     * *Формат*: `07 липня 2003 р.`
   * **Плашка 2 (Посадка на поверхню)**:
     * *Поле БД*: `missions.landing_date`
     * *Формат*: `25 січня 2004 р.`
   * **Плашка 3 (Фінал місії / Статус)**:
     * *Поле БД*: `missions.end_date`
     * *Формат*: `10 червня 2018 р. (5 111 Солів зв'язку)`
   * **Плашка 4 (Кількість залишеного обладнання)**:
     * *Джерело*: `artifacts.count()`
     * *Формат*: `1 марсохід + 2 точки посадки` (бейдж із лічильником).

### 🟢 БЛОК 2: Історія та Наукова Спадщина Місії
Оповідальний блок, який розкриває передісторію та мету запуску.

#### Поля блоку та прив'язка до бази даних:
1. **Підзаголовок H2**: `Мета експедиції та наукове значення`.
2. **Основний текст опису**:
   * *Поле БД*: `missions.summary`
   * *Текст*: Повна історія цілей місії (пошук води, аналіз мінералів, геологія).
   * *Оформлення*: Чистий текст з інтерліньяжем 1.7 для комфортного читання школярами.
3. **Callout-блок «Чому це важливо?» (Зі значком 💡)**:
   * Коротке резюме в 2 рядки простою мовою:
   * *«Марсохід Opportunity був розрахований лише на 90 днів роботи, але пропрацював майже 15 років і проїхав понад 45 кілометрів, підтвердивши наявність води в минулому Марса!»*.

### 🟢 БЛОК 3: Маніфест Залишеного Обладнання (Ключовий блок!)
Показує повний перелік артефактів, які ця місія назавжди залишила на поверхні планет.

#### Як відображається:
Сітка інтерактивних карток (Grid 2 або 3 колонки).

#### Поля на кожній картці артефакту:
* *Джерело*: `SELECT * FROM artifacts WHERE mission_id = :id`
1. **Фото апарата (Thumbnail)**:
   * *Поле БД*: `artifact_media.media_url` (перше фото з `media_category='SURFACE_PHOTO'` або `LAST_KNOWN_PHOTO`).
2. **Назва артефакту**:
   * *Поле БД*: `artifacts.name` (наприклад, `Opportunity Rover (MER-B)`).
3. **Бейдж типу обладнання**:
   * *Поле БД*: `artifacts.artifact_type` (кольорові чіпи: `ROVER 🚜`, `LANDER 📡`, `DESCENT_STAGE 🛸`, `RETRO_REFLECTOR 🪞`, `SAMPLE_TUBE 🧪`).
4. **Бейдж операційного статусу**:
   * *Поле БД*: `artifacts.operational_status`
   * `DORMANT 🔴` — знеструмлений / засипаний пилом.
   * `PASSIVE_ACTIVE 🟢` — пасивно працює (лазерний відбивач).
   * `DESTROYED 💥` — планово розбитий об ґрунт.
5. **Локація посадки**:
   * *Поле БД*: `artifacts.location_name` (наприклад, `Perseverance Valley` або `Mare Tranquillitatis`).
6. **Координати на планеті**:
   * *Поля БД*: `artifacts.latitude`, `artifacts.longitude` (наприклад, `-1.9462° S, 354.4734° E`).
7. **Посаджена маса**:
   * *Поле БД*: `artifacts.mass_kg` (наприклад, `185.0 кг`).
8. **Кнопки дій на картці**:
   * `👁️ Відкрити 3D картку` — плавно відкриває Drawer з інтерактивною 3D-моделлю `.glb` та монологом.
   * `📍 Показати на 3D мапі` — перенаправляє на головну сторінку та анімує камеру Three.js прямо на координати цього апарата.

### 🟢 БЛОК 4: Зведені Наукові Відкриття Місії
Показує прилади, які стояли на борту, та конкретні наукові факти.

#### Як відображається:
Акордеон Chakra UI або перелік карток із вкладками.

#### Поля блоку:
* *Джерело*: `SELECT * FROM scientific_discoveries WHERE artifact_id IN (місія)`
1. **Код приладу**: `scientific_discoveries.instrument_acronym` (наприклад, `Pancam`, `APXS`, `MIMOS II`, `Mini-TES`).
2. **Повна офіційна назва інструменту**: `scientific_discoveries.instrument_full_name` (наприклад, `Panoramic Camera`).
3. **Заголовок відкриття**: `scientific_discoveries.title` (наприклад, *«Виявлення гематитових кульок "Blueberries"»*).
4. **Пояснення простою мовою для дітей/школярів**:
   * `scientific_discoveries.kid_friendly_story`
   * *«Крихітні сірі кульки, схожі на ягоди чорниці, які могли вирости лише в теплій стоячій воді стародавнього марсіанського озера!»*.
5. **Точний науковий факт з архіву NASA PDS**:
   * `scientific_discoveries.scientific_fact`
   * *«Кристалічний гематит виявлено спектрометром Mössbauer MIMOS II з концентрацією заліза...»*.

### 🟢 БЛОК 5: Ролики Спільноти про цю Місію (Community Shorts / Reels)
Вертикальні відеоролики, присвячені цій місії, змонтовані у «Фабриці контенту» або надіслані користувачами.

#### Поля блоку:
* *Джерело*: `SELECT * FROM community_publications WHERE mission_id = :id AND is_approved = true`
1. **Вертикальний плеєр 9:16**: Вбудований YouTube Shorts або TikTok плеєр за адресою `community_publications.video_url`.
2. **Назва ролика**: `community_publications.title` (наприклад, *«Останній день Opportunity: шторм, який не вщух»*).
3. **Автор**: `community_publications.author_name` (наприклад, `@SpaceGeek99`).
4. **Обов'язковий блок цитованих першоджерел (Citations)**:
   * `community_publications.source_references`
   * Посилання на фотографії NASA PIA (наприклад, `PIA22521`) та каталоги PDS, які автор використав у відео.
5. **Кнопка поруч**: `+ Додати власне відео про цю місію` (відкриває модалку подачі посилання на премодерацію).

### 🟢 БЛОК 6: Офіційні Референси та Футер NASA

3. **Навігаційна кнопка**: `⬅️ Повернутися до 3D мапи планет`.

## 💻 4. Рекомендації для верстки на Chakra UI v3

* **Контейнер**: `<Container maxW="container.xl" py={8}>`.
* **Hero Карточки**: `<SimpleGrid columns={{ base: 2, md: 4 }} gap={4}>`.
* **Маніфест обладнання**: `<SimpleGrid columns={{ base: 1, md: 2, lg: 3 }} gap={6}>`.
* **Кольори**:
  * Фон сторінки: `#0A0B10`.
  * Картки: `bg="rgba(18, 20, 29, 0.7)"` з `backdropFilter="blur(10px)"` та `border="1px solid rgba(255, 255, 255, 0.08)"`.
  * Заголовки: `color="#FFFFFF"`, шрифт `Space Grotesk`.
  * Бейджі статусів: `colorPalette="red"` для DORMANT, `colorPalette="green"` для PASSIVE_ACTIVE.
