# Дизайн-Завдання для Десктопної «Фабрики Контенту»: Екрани, Ноди та Safe Zones (TASK_DESIGN_EDITOR_DESKTOP.md)

> **Для кого**: Дизайнер інтерфейсів (Віолетта) та Розробник десктопного клієнта (Нікіта).  
> **Рівень складності**: «Розжовано як для новачка / без води» — чіткий покроковий перелік екранів, конфігурація нодового редактора та Safe Zones.  
> **Технічний стек**: **Tauri v2 + React 19 + Chakra UI v3 + `@xyflow/react` (React Flow)**. (Строго БЕЗ Tailwind CSS!).  
> **Принцип роботи**: **Local-First / Клієнтська автономія** (усі чернетки та монтаж відбуваються на комп'ютері користувача).

## 📐 1. Головні SMM-Вимоги до Дизайну Відео (Стандарт 9:16)

Десктопний додаток призначений для виробництва вертикальних роликів для **YouTube Shorts, TikTok та Instagram Reels**.

### Базові розміри та «Мертві зони» (Safe Zones):
* **Роздільна здатність**: строго $1080 \times 1920$ px ($9:16$).
* **Цільовий хронометраж**: стандарт **~40 секунд** (діапазон 15–60 секунд).
* **Мертві зони інтерфейсу соцмереж** (де текст перекривається кнопками):
  1. **Верхня мертва зона**: $220$ px зверху (перекривається рядком пошуку соцмережі та назвою звуку).
  2. **Нижня мертва зона**: $420$ px знизу (перекривається назвою акаунта, описом ролика та коментарями).
  3. **Права мертва зона**: $150$ px праворуч (перекривається кнопками Лайк, Коментарі, Поділитися, Зберегти).
* **Ефект Pillow-box (Обробка архівних фото)**:
  * Історичні фотографії NASA з пропорціями $4:3$ або квадрат не обрізаються по-варварськи.
  * Система генерує естетичний розмитий задній фон із самого зображення, розміщуючи різкий оригінал по центру.

## 🖥️ 2. Точний Перелік Екранів: Що саме малювати та кодити

У десктопному застосунку створюється **єдине ергономічне двопанельне вікно** (Спліт-екран: зліва Нодовий граф, справа Інтерактивний плеєр) + 2 допоміжні модалки.

```
+-----------------------------------------------------------------------------------+
|                        ВЕРХНІЙ ТУЛБАР (HEADER / ACTION BAR)                       |
+-------------------------------------------------+---------------------------------+
|                                                 |                                 |
|            ЛІВА ПАНЕЛЬ (60% ШИРИНИ):            |   ПРАВА ПАНЕЛЬ (40% ШИРИНИ):    |
|             НОДОВИЙ ГРАФ РОБОТИ                 |    ІНТЕРАКТИВНИЙ 9:16 ПЛЕЄР     |
|              (@xyflow/react)                    |     (SAFE ZONES PREVIEW)        |
|                                                 |                                 |
|  [ArtifactNode] -> [ScriptNode] -> [TTSNode]   |  +---------------------------+  |
|                          |                      |  |     Верхня зона 220px     |  |
|                          v                      |  |   [БЕЗПЕЧНА ЗОНА 9:16]    |  |
|              [CompositeNode] -> [PublishNode]   |  |   (3D / Фото + Субтитри)  |  |
|                                                 |  |    Нижня зона 420px       |  |
|                                                 |  +---------------------------+  |
|                                                 |  [Кнопка Рендер] [Експорт]      |
+-------------------------------------------------+---------------------------------+
```

---

### ЕКРАН 1: Верхній Тулбар (Action Header)

Займає верхні 60 px вікна програми:
1. **Зліва**: Логотип `CosmoLost Studio` + Назва поточного проєкту (наприклад, `Opportunity_Last_Sol_Draft`).
2. **По центру**: Статус рендерингу (бейджі: `DRAFT ⚪`, `RENDERING 🟡 (45%)`, `RENDERED 🟢`, `FAILED 🔴`).
3. **Справа (Керування залізом та Рендером)**:
   * **Повзунок таймауту GPU (`render_timeout_sec`)**: меню вибору (30с, 40с дефолт, 90с для повільних ноутбуків, 180с).
   * Кнопка: `▶️ Змонтувати ролик (FFmpeg)`.
   * Кнопка: `🚀 Опублікувати / Експорт`.

---

### ЕКРАН 2: Полотно Нодового Графа (Ліва панель — `@xyflow/react`)

Користувач бачить візуальний конвеєр створення ролика у вигляді з'єднаних нод-карток:

#### 1. Нода `ArtifactSourceNode` (Вхідні дані):
* Заголовок: `Артефакт NASA 🪐`.
* Поле вибору планети (Місяць / Марс).
* Випадаючий список пошуку артефакту (підтягує дані з `GET /api/v1/portal/artifacts/`).
* Міні-прев'ю обраного апарата + координати.
* Вихідні сокети: `Metadata`, `Photos[]`, `Discoveries`.

#### 2. Нода `ScriptTemplateNode` (Рубрика та Сценарій):
* Заголовок: `Рубрика та Сценарій 📜`.
* Вибір рубрики:
  * `Останній день на зв'язку (~40с)`
  * `Як це працює? (~35с)`
  * `Таємниці Місяця (~40с)`
* **Поле мотивації вибору (`selection_reason`)**: обов'язкове текстове поле (від 10 до 500 символів), де автор пише, чому саме цей факт обрано (наприклад: *«Річниця засипання сонячних батарей бурею»*).
* **Акордеон 4 слайдів таймлайну**:
  * Слайд 1: Хук (3.5с) — вступне питання.
  * Слайд 2: B-roll факти (14с) — показ архівних фотографій.
  * Слайд 3: Драматичний пік (16.5с) — згасання телеметрії.
  * Слайд 4: Фінал і Seamless Loop (6с) — заклик перейти на вебпортал.
* Кнопка внизу ноди: **`✨ Придумати тему для наступного відоса`** (викликає Smart Next Topic Engine).

#### 3. Нода `AudioTTSNode` (Синтез мови та ліпсінк):
* Заголовок: `Озвучка та Аудіо 🎙️`.
* Вибір мови: `Українська (uk-UA-OstapNeural)` або `English (en-US-GuyNeural)`.
* Перемикач: `Прискорення 1.1x` та `Jump-cut (видалення пауз > 0.15с)`.
* Кнопка: `🔊 Прослухати аудіодоріжку`.
* Шкала гучності та RMS-індикатор амплітуди для ліпсингу.

#### 4. Нода `VisualCompositeNode` (Композитинг та Pillow-box):
* Заголовок: `Візуальний монтаж 🎬`.
* Галочка: `Pillow-box ефект для архівних фото 4:3 (розмитий фон)`.
* Перемикач аватара: `Вимкнено` / `PNGTuber (Дефолтний від Віолетти)` / `Кастомний аватар`.
* Позиція аватара: `Нижній правий кут` або `Центр`.
* HUD Телеметрія: `Показувати Sci-Fi координати та заряд батареї`.

#### 5. Нода `SocialPublishNode` (Дистрибуція):
* Заголовок: `Публікація та Експорт 📤`.
* Чекбокси каналів: `YouTube Shorts`, `Telegram-канал`, `Зберегти в папку на диску`.
* Автоматично сформований 3-рядковий SEO опис + Pin Comment.

### ЕКРАН 3: Інтерактивний 9:16 Монітор Прев'ю (Права панель)

Точна візуалізація того, як виглядатиме ролик у мобільному телефоні глядача:
1. **Рамка смартфона 9:16**:
   * Відображає результат композитингу в реальному часі (Canvas / Video-тег).
2. **Перемикач «Показати безпечні зони» (Toggle Safe Zones)**:
   * При ввімкненні накладає напівпрозору червону сітку на мертві зони (верх 220px, низ 420px, право 150px).
   * Дозволяє відразу бачити, що текст субтитрів не закриє опис ролика у TikTok!
3. **Кнопки швидкої дії під монітором**:
   * Кнопка: `📋 Скопіювати повний опис та хештеги`.
   * Кнопка: `💬 Скопіювати закріплений коментар (Pin Comment)`.
   * Кнопка: `📂 Відкрити папку з готовим відео` (відкриває Windows Explorer із виділеним файлом `.mp4`).

---

### ЕКРАН 4: Модальне вікно кастомізації PNGTuber аватара

Відкривається при кліку на налаштування аватара:
* Сітка 4 емоцій $\times$ 2 фази рота = **8 спрайтів**:
  1. `Idle (Закритий / Відкритий рот)`
  2. `Expert (Закритий / Відкритий рот)`
  3. `Shock (Закритий / Відкритий рот)`
  4. `Hype (Закритий / Відкритий рот)`
* Кнопка `Завантажити свій PNG` для кожної клітинки.
* Повзунок тесту чутливості мікрофона: коли користувач говорить у мікрофон, рот аватара на прев'ю відкривається у такт голосу!

---

### ЕКРАН 5: Модалка Smart Next Topic Engine («Придумати наступну тему»)

Відкривається при натисканні на відповідну кнопку в `ScriptTemplateNode`:
* Відправляє запит на `POST /api/v1/editor/recommend-next-topic/`.
* Показує красиву картку наступного артефакта:
  * **Рекомендований апарат**: *Spirit Rover (MER-A)*.
  * **Сюжетний міст (Narrative Bridge)**: *«Поки Opportunity перемагав бурю, його близнюк застряг у пісках кратера Гусєв...»*.
  * **Сюжетний хук**: *«А ви знали, що близнюк застряглого Spirit здійснив справжнє диво?»*.
  * **Закріплений коментар**: *«Чия доля вас вражає більше: Spirit чи Opportunity?»*.
* Кнопка: `✅ Застосувати та створити наступний ролик`.

## 🛠️ 3. Стани монтажного процесу (UX Flow)

1. **Стан «Чернетка» (Draft)**: Кнопка рендеру активна, помилок немає.
2. **Стан «Рендеринг» (Rendering)**:
   * Кнопка рендеру блокується, з'являється круговий прогрес-бар з відсотками (наприклад, `Рендеринг кадру 420 / 1200 [35%]`).
   * Якщо рендеринг триває на повільному залізі — користувач бачить напис: *«Працює FFmpeg. Відео обробляється, зачекайте...»* (без зависань чи помилок).
3. **Стан «Готово» (Rendered)**:
   * Звуковий сигнал завершення (приємний звук успіху).
   * Зелений бейдж `Готово до публікації`.
   * Відео з'являється в плеєрі прев'ю.

## 🚀 4. Як це приміняється у коді Frontend (React + Chakra UI v3)

Структура папок у `desktop-client/src/` (за стандартом FSD):
```
desktop-client/src/
├── app/                  # Tauri провайдери, Chakra UI v3 тема
├── pages/
│   └── editor-page/      # Головний екран спліт-редактора
├── widgets/
│   ├── node-flow-canvas/ # Полотно графа React Flow (@xyflow/react)
│   ├── safe-zone-player/ # 9:16 монітор із накладанням мертвих зон
│   └── top-action-bar/   # Верхній тулбар рендеру та статусу
├── features/
│   ├── build-ffmpeg/     # Виклик команди рендерингу FFmpeg через Tauri IPC
│   ├── customize-avatar/ # Налаштування спрайтів PNGTuber
│   ├── suggest-topic/    # Генератор наступної теми
│   └── publish-social/   # Публікація в YouTube / Telegram / Експорт
├── entities/
│   ├── project/          # Локальна модель проекту (%APPDATA%)
│   ├── template/         # SMM-рубрики та структура слайдів
│   └── artifact-asset/   # Монтажний пакет фактів
└── shared/
    ├── ui/               # Базові кнопки, модалки, повзунки Chakra UI v3
    └── lib/              # Tauri IPC клієнт (invoke) та clipboard
```
