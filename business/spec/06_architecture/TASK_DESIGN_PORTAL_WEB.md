### ЕКРАН 1: Головна сторінка — 3D Інтерактивний Глобус (`/`)

Це головний екран, куди потрапляє користувач. 85% площі займає 3D-сфера Three.js.

#### Елементи екрана (зверху донизу):
1. **Header (Верхнє меню)**:
   * Логотип: `CosmoLost` із неоновою орбітальною іконкою.
   * Навігація: `3D Карта`, `Каталог`, `Відео спільноти`, `Про проект`.
   * Кнопка швидкого підключення FastMCP для ШІ: бейдж `AI Gateway (MCP)`.
2. **Floating Planet Switcher (Перемикач планет по центру зверху)**:
   * Сегментований перемикач (Segmented Control): `Місяць (Moon)` / `Марс (Mars)`.
   * При кліку: камера Three.js плавно обертається, завантажується відповідна текстура NASA Treks WMTS.
3. **Floating Filter Bar (Плаваюча панель фільтрів зліва або згори)**:
   * Пошуковий інпут: `🔍 Пошук артефакту...` (Fuzzy / Full-text пошук).
   * Чіпи фільтрів типів: `Всі`, `Ровери (ROVER)`, `Посадкові модулі (LANDER)`, `Відбивачі (RETRO_REFLECTOR)`, `Інструменти (INSTRUMENT)`.
   * Перемикач `Тільки обрані (Tier 1 ⭐)`.
   * Лічильник знайдених: `Показано: 42 / 120 об'єктів`.
4. **Three.js Сцена (Центр)**:
   * Сфера небесного тіла з високою деталізацією тайлів NASA.
   * Неонові маркери точок артефактів.
   * **Кластеризація `<500м`**: якщо об'єкти розташовані в одній зоні (наприклад, база Apollo 11), відображається круглий бейдж `(3)`, який при наближенні плавно розкривається (Spiderfy).
5. **Hover Tooltip (Спливаюча картка при наведенні на маркер)**:
   * Фото артефакта 80x80 px.
   * Назва (наприклад, *Opportunity Rover*).
   * Координати та кратер (*Perseverance Valley*).
   * Текст: `Клікніть, щоб розкрити картку ➔`.

### ЕКРАН 2: Висувна панель / Drawer артефакту (`/artifacts/:id`)

Відкривається плавно з правої частини екрана при кліку на маркер або за прямим посиланням із соцмереж.

#### Секції всередині панелі:
1. **Hero-блок**:
   * Бейдж статусу: `DORMANT 🔴` або `PASSIVE ACTIVE 🟢`.
   * Назва артефакту: заголовок H1 (*Opportunity Rover (MER-B)*).
   * Назва місії: лінк на місію (*Mars Exploration Rover*).
   * Каталожний бейдж: `Офіційне обладнання NASA ✅`.
2. **Інтерактивний 3D-переглядач (3D GLB Viewer)**:
   * Блок розміром 100% ширини $\times$ 320 px.
   * Завантажує `.glb` файл через `GLTFLoader` з NASA GitHub CDN.
   * Кнопки під 3D: `Обертати`, `На весь екран`, `Скинути ракурс`.
3. **Блок сторітелінгу «Щоденник останнього Сола» (First-Person Story)**:
   * Стилізований під бортовий термінал блок із монологом від першої особи **англійською мовою (en-US)**.
   * Цитата: *«My clock stopped on Sol 5111. Darkness fell across Meridiani Planum...»*.
   * Дата завершення роботи та причина виходу з ладу (пилова буря).
4. **Вкладки з детальною інформацією (Tabs)**:
   * **Вкладка 1: Наукові відкриття (Discoveries)**:
     * Список приладів у вигляді аккордеону (Pancam, APXS, SEIS).
     * Для кожного приладу: назва, пояснення простою мовою для дітей/школярів («Блакитні кульки води») та точний факт з архіву NASA PDS.
   * **Вкладка 2: Фотоархів NASA**:
     * Галерея архівних знімків із кодами `PIA22521`.
     * Клік на фото $\to$ збільшення на весь екран (Lightbox).
   * **Вкладка 3: Маршрут та Телеметрія (для роверів)**:
     * Графік пробігу (Одометрія в метрах) та показники батарей / пилу.

  * Назва та піктограма типу (маленький значок ровера чи антени).

### ЕКРАН 4: Відеогалерея Спільноти (`/community`)

Вітрина відеоконтенту, згенерованого за допомогою нашої «Фабрики контенту» або надісланого спільнотою.

#### Елементи:
* Сітка вертикальних відео 9:16 (YouTube Shorts / TikTok iframe-плеєри).
* Під кожним відео:
  * Заголовок ролика.
  * Автор контенту (`@SpaceGeek99`).
  * **Блок верифікованих наукових першоджерел (Citations)**: клікабельні посилання на фотографії NASA PIA та статті PDS, які були використані у відео.
* Кнопка у шапці: `+ Подати власне відео про місію`.
  * Відкриває просту модалку з 4 полями: Місія, Посилання на YouTube/TikTok, Список використаних джерел, Нікнейм автора.

## 🛠️ 3. 4 Обов'язкові UX-стани для кожного компонента

Дизайнер і фронтендер зобов'язані закласти 4 стани:
1. **Loading State (Завантаження)**: Скелетони Chakra UI (`<Skeleton height="200px" />`) замість порожнього білого екрана.
2. **Empty State (Порожньо)**: Коли пошук не дав результатів — ілюстрація марсіанського піску + текст: *«Жодного покинутого обладнання не знайдено. Спробуйте змінити фільтри»* + кнопка `Скинути фільтри`.
3. **Error State (Помилка мережі)**: Повідомлення про помилку + кнопка `Спробувати знову`.
4. **Success State (Успіх)**: Плавна анімація появи контенту (`fade-in` 250 мс).

## 🚀 4. Як це приміняється у коді Frontend (React + Chakra UI v3)

Структура папок за стандартом Feature-Sliced Design (FSD):
```
web-client/src/
├── app/                  # Провайдери Chakra UI v3, роутер
├── pages/
│   ├── map-page/         # Головний екран 3D Three.js глобуса
│   ├── catalog-page/     # Табличний каталог
│   └── community-page/   # Відео спільноти
├── widgets/
│   ├── globe-viewer/     # Three.js сцена з планетою та маркерами
│   ├── artifact-drawer/  # Висувна картка з 3D GLB та вкладками
│   └── filter-bar/       # Плаваюча панель пошуку та чіпів
├── features/
│   ├── switch-planet/    # Перемикання Moon / Mars
│   ├── filter-artifacts/ # Фільтрація точок за типом і статусом
│   └── submit-video/     # Форма подачі відео на модерацію
├── entities/
│   ├── artifact/         # Типи, API репозиторій, карточка UI
│   ├── celestial-body/   # Типи планет і тайлів
│   └── mission/          # Дані місії
└── shared/
    ├── ui/               # Базові кнопки, модалки, скелетони Chakra UI
    └── api/              # Axios/Fetch клієнт до /api/v1/portal/
```
