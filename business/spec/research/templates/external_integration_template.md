## 5. Структура даних (Data Schemas & DTOs)

### 5.1. Запит до провайдера (Request Payload)
* **Ендпоінт**: `[METHOD] https://api.provider.com/v1/...`
* **Обов'язкові заголовки (Headers)**:
  ```http
  Authorization: Bearer <TOKEN>
  Content-Type: application/json
  Idempotency-Key: <UUID>
  ```
* **Тіло запиту (JSON Payload)**:
  ```json
  {
    "external_param_1": "string",
    "external_param_2": 0,
    "metadata": {
      "internal_user_id": "string",
      "internal_order_id": "string"
    }
  }
  ```

### 5.2. Відповідь провайдера (Response Payload)
* **Очікуваний статус**: `200 OK` / `201 Created`
* **Тіло відповіді (JSON Schema)**:
  ```json
  {
    "id": "ext_id_12345",
    "status": "success",
    "created_at": 1731574800,
    "data": {}
  }
  ```

### 5.3. Вхідний вебхук / подія (Webhook / Event Payload, якщо є)
* **Шлях прийому**: `POST /api/v1/integrations/[provider]/webhooks/`
* **Заголовок підпису**: `X-Provider-Signature: t=1731574800,v1=...`
* **Тіло події (JSON Schema)**:
  ```json
  {
    "event_id": "evt_98765",
    "event_type": "entity.updated",
    "payload": {}
  }
  ```
