## 1. Мета та ключові метрики

Створення вірусних відео для CosmoLost розглядається як **конвеєрна інженерна задача**.
Головні оптимізаційні метрики:
1. **Viewed vs Swiped Away (Вирішили подивитися vs Прогорнули)**: Цільовий поріг $> 65\text{--}70\%$. Залежить суто від перших 1.5–3 секунд (Хука).
2. **Retention Rate (Утримання уваги)**: Цільовий показник для ролика 30–45 секунд — вище $70\text{--}85\%$.
3. **Loop Rate (Коефіцієнт зациклення)**: Програвання відео по колу завдяки безшовному склеюванню кінця і початку, що дає алгоритмічний сигнал $120\text{--}200\%$ перегляду.

## 2. Анатомія та таймлайн вірусного науково-популярного ролика

```
[0.0s - 3.0s]       [3.0s - 35.0s]                 [35.0s - 45.0s]
+-----------------+-------------------------------+----------------------+
|  ХУК (HOOK)     |  ОСНОВНИЙ БЛОК (М'ЯСО)        |  ПАНЧЛАЙН / LOOP     |
|  - Провокація   |  - 3 наукові тези без води    |  - Кульмінація       |
|  - Повноекранний|  - Перебивки B-roll кожні 3с |  - Зациклена фраза   |
|    PNGTuber     |  - Аватар у кутку + 3D сцена |  - Заклик на сайт    |
|  - SFX Whoosh   |  - Sci-Fi HUD телеметрія      |  - Pin Comment байт  |
+-----------------+-------------------------------+----------------------+
```

### 2.1. Хук (0–3 секунди)
* Заборонено: привітання, вступи типу «Привіт, сьогодні я розповім...».
* Обов'язково: парадоксальний або драматичний факт: *«Цей марсохід помер 6 років тому, але вчені досі отримують сигнали з його кратера»*.
* Візуал: PNGTuber займає до 40% площі по центру екрана, різкий наїзд камери, динамічний звуковий ефект (*whoosh* або *glitch*).

### 2.2. Основна частина (3–35 секунд)
* Аватар переміщується в лівий нижній кут (вище мертвої зони, ~400 px від низу) і жестикулює указкою на центр екрана.
* У центрі: 3D-модель артефакту, вибух-схема приладів або процедурна симуляція кратера.
* Перебивки (B-roll): зміна плану або графічного акценту кожні **3–5 секунд**.
* Телеметрія збоку: напівпрозорий Sci-Fi HUD або біжучий рядок термінала з координатами та значеннями заряду/пилу (спонукає ставити на паузу, що підвищує утримання до 200%).

### 2.3. Панчлайн та Loop (35–45 секунд)
* Безшовне зациклення (Seamless Loop): остання фраза переходить у перше речення відео.
* Короткий CTA: *«Точні координати та 3D-мапа вже на CosmoLost. Посилання в описі»*.

## 4. Специфікація PNGTuber (State Machine)

Замість ресурсоємного 3D-трекінгу обличчя використовується легкий **PNGTuber з 4 реактивними станами**:

| Стан аватара | Спрайт | Коли активується |
| :--- | :--- | :--- |
| **`STATE_IDLE`** | Спокійне обличчя (рот закритий / відкритий під амплітуду аудіо) | Базове оповідання, спокійний опис фактів |
| **`STATE_EXPERT`** | Поправляє окуляри або тримає руку біля підборіддя | Пояснення складної інженерної будови датчика або формули |
| **`STATE_SHOCK`** | Широко розплющені очі, фейспалм або здивування | Момент аварії, замерзання, зламу лопаті чи пилової бурі |
| **`STATE_HYPE`** | Посмішка, лазерні очі або піднятий догори палець | Науковий прорив, рекорд пройденої відстані, знахідка води |

## 5. Аудіодизайн та динамічні субтитри

* **Обробка голосу (TTS / Озвучка)**:
  * Прискорення темпу мови: **1.05x–1.15x** від базового темпу.
  * Видалення тиші (Jump-cut): інтервали тиші між реченнями обрізаються до **$< 0.15$ секунди**.
  * Рівень гучності голосу: строго **-6 dB .. -3 dB**.
* **Фонова музика**:
  * Рівень відносно голосу: **-22 dB .. -28 dB**.
  * Жанри: *Synthwave, Dark Synth, Cyberpunk Ambient, Space Lo-Fi*.
* **Звукові ефекти (SFX)**:
  * Whoosh / Glitch — при зміні слайдів та перельоті аватара.
  * Typewriter / Click — при появі слів субтитрів та плашок телеметрії.
* **Кінетична типографіка (Субтитри)**:
  * Шрифт: масивний гротеск без зарубок (*Montserrat Black, Inter ExtraBold*).
  * Розмір блоку: **2–4 слова одночасно** строго в центральній третині екрана.
  * Кольорове підсвічування активного слова: неоново-жовтий (`#FFD700`) або зелений (`#00FF66`) із чорною обводкою (Stroke).
