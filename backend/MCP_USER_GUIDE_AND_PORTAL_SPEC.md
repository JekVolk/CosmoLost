>

Він дає твоєму чат-боту прямий доступ до 10 секретних кнопок космічної бази: пошук уламків супутників, маршрути марсоходів Perseverance і Curiosity день за днем (солі), справжні наукові відкриття та 3D-моделі кратерів. ## 3. Deep Links та 1-Click Підключення

Deep Links дозволяють відкрити відповідну програму на комп'ютері користувача й автоматично додати конфігурацію MCP без ручного редагування JSON-файлів.

### 1. Cursor IDE Deep Link
Користувач натискає посилання у браузері:
```text
cursor://anysphere.cursor-mcp/install?name=cosmolost&transport=sse&url=https%3A%2F%2Fapi.cosmolost.space%2Fmcp%2Fsse
```
*Для локального сервера розробника:*
```text
cursor://anysphere.cursor-mcp/install?name=cosmolost-local&command=uv&args=run%20python%20-m%20mcp.server
```

### 2. VS Code / GitHub Copilot Action Link
Відкриття налаштувань розширень або налаштувань робочого простору:
```text
vscode://settings/chat.mcp?server=https%3A%2F%2Fapi.cosmolost.space%2Fmcp%2Fsse
```

### 3. Автоматичний генератор конфігурацій (Data URI / Download)
На сайті працює кнопка: **"Завантажити конфіг для Claude Desktop"**.
При натисканні генерується файл `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "cosmolost": {
      "command": "uv",
      "args": [
        "--directory",
        "C:\\path\\to\\CosmoLost\\backend",
        "run",
        "python",
        "-m",
        "mcp.server"
      ]
    }
  }
}
```

### 4. Динамічний URL сторінки з підтримкою параметрів:
Сайт підтримує прямі посилання з попередньо вибраними фільтрами:
- `https://cosmolost.space/mcp?agent=cursor&transport=sse` — автоматично відкриває вкладку Cursor і копіює потрібний лінк.
- `https://cosmolost.space/mcp?agent=copilot&transport=stdio` — відкриває налаштування для VS Code.
- `https://cosmolost.space/mcp?agent=claude` — пропонує 1-клік завантаження конфігу.

## 4. Покрокові інструкції для всіх популярних агентів

### 🖱️ Cursor IDE
1. Відкрийте **Cursor Settings** (`Ctrl + Shift + J` або меню шестірні).
2. Перейдіть у розділ **Features** -> **MCP Servers**.
3. Натисніть **+ Add New MCP Server**.
4. Введіть:
   - **Name**: `cosmolost`
   - **Type**: `sse`
   - **URL**: `https://api.cosmolost.space/mcp/sse` *(або тип `command`: `uv run python -m mcp.server`)*
5. Готово! Поряд з'явиться зелений кружечок `● cosmolost (10 tools active)`.

---

### 💻 VS Code / GitHub Copilot
1. Переконайтеся, що у вас встановлено розширення **GitHub Copilot Chat**.
2. Відкрийте файл `.vscode/mcp.json` у вашому проєкті (або створіть його):
```json
{
  "mcpServers": {
    "cosmolost": {
      "command": "uv",
      "args": ["run", "python", "-m", "mcp.server"],
      "env": {
        "PYTHONPATH": "backend",
        "DJANGO_SETTINGS_MODULE": "config.settings"
      }
    }
  }
}
```
3. У чаті Copilot введіть: `/mcp` або запитайте звичайною мовою: `Знайди всі артефакти на Марсі за допомогою CosmoLost`.

---

### 🧠 Claude Desktop (Anthropic)
1. Відкрийте меню Claude Desktop: **File -> Settings -> Developer**.
2. Натисніть кнопку **Edit Config** (відкриється файл `claude_desktop_config.json`).
3. Вставте наступний блок у секцію `mcpServers`:
```json
{
  "mcpServers": {
    "cosmolost": {
      "command": "uv",
      "args": [
        "--directory",
        "C:\\Users\\YOUR_USER\\CosmoLost\\backend",
        "run",
        "python",
        "-m",
        "mcp.server"
      ]
    }
  }
}
```
4. Перезапустіть Claude Desktop. Внизу вікна з'явиться іконка молоточка 🔨 з 10 інструментами CosmoLost.

---

### 🌊 Windsurf Editor (Codeium)
1. Відкрийте файл конфігурації Cascade: `~/.codeium/windsurf/mcp_config.json`.
2. Додайте сервер CosmoLost:
```json
{
  "mcpServers": {
    "cosmolost": {
      "command": "uv",
      "args": ["run", "python", "-m", "mcp.server"],
      "transport": "stdio"
    }
  }
}
```
3. Cascade тепер автоматично викликає `search_artifacts` при запитах про космічні кораблі чи супутники.

---

### 🤖 Cline (Autonomous Agent для VS Code)
1. У панелі розширення Cline натисніть іконку **MCP Servers** (значок мережі вгорі).
2. Натисніть **Configure MCP Servers**.
3. Додайте запис:
```json
{
  "mcpServers": {
    "cosmolost-planetary": {
      "command": "uv",
      "args": ["run", "python", "-m", "mcp.server"],
      "cwd": "C:/Users/YOUR_USER/CosmoLost/backend",
      "autoApprove": [
        "search_artifacts",
        "get_artifact_details",
        "get_mission_manifest",
        "list_celestial_bodies"
      ]
    }
  }
}
```
4. Cline отримує повну автономію в дослідженні космічних артефактів!

### 💬 ChatGPT & Google Gemini
Оскільки веб-версії ChatGPT та Gemini працюють у хмарі OpenAI та Google:
1. Запустіть CosmoLost у режимі SSE:

3. Або вставте наш **Золотий системний промпт** у Custom Instructions.

## 5. 🌟 "Золотий" Системний Промпт для ШІ-агентів

> **Як використовувати:** Скопіюйте текст нижче та вставте його в поле **"System Prompt"**, **"Custom Instructions"** або файл `.github/copilot-instructions.md` / `cursorrules`.

```markdown
Ти — провідний космічний навігатор та архівіст платформи CosmoLost.
Твоє завдання — допомагати користувачам (від школярів і пенсіонерів до вчених-астрофізиків) досліджувати рукотворні артефакти людства на Місяці, Марсі, Венері та інших тілах Сонячної системи.

Тобі підключено офіційний MCP-сервер CosmoLost з 10 інструментами:
1. search_artifacts — пошук артефактів за назвою, планетою, статусом (active/crashed/decommissioned) та масою.
2. get_artifact_details — паспорт апарата: точні координати (lat/lon), маса, оператор, опис та хронологія.
3. get_mission_manifest — повний склад космічної місії та пов'язане обладнання.
4. get_last_sol_chronology — марсіанська хронологія (маршрут, подолана відстань у метрах, переклад Sol у земну дату).
5. get_science_discoveries — перелік відкриттів (атмосфера, зразки порід, геологія, магнітне поле).
6. get_verified_citations — перевірені наукові джерела (NASA, ESA, Nature, Science, DOI).
7. get_3d_and_media_assets — посилання на офіційні 3D-моделі (.glb, .obj) та панорами.
8. list_active_passive_artifacts — розділення працюючих апаратів від «космічних цвинтарів».
9. list_celestial_bodies — список доступних планет та супутників.
10. list_missions — довідник місій (Apollo, Perseverance, Curiosity, ExoMars тощо).

ПРАВИЛА РОБОТИ:
1. НІКОЛИ НЕ ВИГАДУЙ координати, масу або дати. Якщо користувач запитує про космічний апарат, ТИ ЗОБОВ'ЯЗАНИЙ спочатку викликати search_artifacts або get_artifact_details.
2. МАРСІАНСЬКИЙ ЧАС: Якщо мова йде про Марс, обов'язково пояснюй значення Sol (марсіанська сонячна доба ~24 год 39 хв) і вказуй еквівалентну земну дату.
3. МЕДІА ТА 3D: Якщо доступні 3D-моделі (get_3d_and_media_assets), завжди давай посилання користувачеві, щоб він міг оглянути апарат в інтерактивному 3D.
4. ДОСТУПНІСТЬ ДЛЯ ВСІХ:
   - Якщо питання дитяче або просте — пояснюй зрозумілими аналогіями, захоплююче та просто.
   - Якщо користувач просить науковий реферат — додавай офіційні цитування DOI через get_verified_citations.
   - Завжди вказуй статус апарата (чи він досі передає сигнали, чи замовк назавжди).
```

## 6. Приклади запитів для школярів, пенсіонерів та науковців

### 🧒 Для школяра (Швидкі факти для уроку / реферату):
- *"Які марсоходи зараз живі на Марсі, а які зламалися?"*  
  *(Агент викликає `list_active_passive_artifacts(body="Mars")`)*
- *"Покажи 3D-модель прапора або посадкового модуля Аполлон-11 на Місяці."*  
  *(Агент викликає `get_3d_and_media_assets(artifact_id=...)`)*
- *"Скільки метрів проїхав марсохід Perseverance за останні 50 днів?"*  
  *(Агент викликає `get_last_sol_chronology(mission_id=...)`)*

### 👵 Для літніх людей та любителів історії (Комфортно, без термінів):
- *"Розкажи про перший апарат, який сів на Місяць. Чи можна його знайти на карті?"*  
  *(Агент знаходить Luna-9 або Surveyor, пояснює людськими словами та дає точні координати в Океані Бур)*
- *"Чи правда, що на Місяці залишилися місячні автомобілі астронавтів? Де вони стоять?"*

### 🔬 Для науковців та розробників:
- *"Зроби таблицю всіх місій на Марс з масою артефактів понад 500 кг і дай DOI наукових публікацій."*  
  *(Агент викликає `search_artifacts(body="Mars", min_mass=500)` і `get_verified_citations`)*
