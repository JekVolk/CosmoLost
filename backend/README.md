# Backend

Ця директорія містить серверну частину проєкту **CosmoLost**.

## Стек та інструменти:
- **Пакетний менеджер:** `uv` (швидкий менеджер пакетів та віртуальних середовищ для Python).
- **Фреймворк:** `Django` + `Django REST Framework` (DRF).
- **Черги та асинхронні задачі:** `Django tasks` (фонова обробка задач).

## Що тут повинно бути:
- **web-api:** API ендпоінти, серіалізатори та авторизація для взаємодії з веб-клієнтом (`web-client`).
- **desktop-api:** Спеціалізоване API для десктопного клієнта (`desktop-client`).
- **MCP (Model Context Protocol):** Сервери та інтеграції MCP для комунікації з мовними моделями/агентами.
- **Loader:** Модулі завантаження та первинної обробки даних (loaders / pipelines).
- **Скіли (Skills):** Інтеграції функціональних інструментів та скілів для ШІ/асистентів.
