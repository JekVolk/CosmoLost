# Desktop Client

Ця директорія містить десктопний застосунок проєкту **CosmoLost**.

## Стек та архітектура:
- **Tauri:** Кросплатформенний десктопний фреймворк на базі Rust та веб-технологій.
- **FSD (Feature-Sliced Design):** Організація фронтенд-коду за методологією Feature-Sliced Design.
- **Git процес:** Робота, рев'ю та злиття змін відбуваються строго через **Гіт пулреквест (Git Pull Request)**.

## Що тут повинно бути:
- Конфігурація та нативна частина Tauri (`src-tauri` на Rust).
- Фронтенд-частина клієнта, побудована за архітектурою FSD (`app`, `pages`, `widgets`, `features`, `entities`, `shared`).
- Інтеграція з бекендом через `desktop-api`.
- Специфікації збірки під цільові операційні системи (Windows, macOS, Linux).
