# Web Client

Ця директорія містить клієнтську веб-частину проєкту **CosmoLost**.

## Архітектура:
- **FSD (Feature-Sliced Design):** Проєкт організовується за методологією Feature-Sliced Design.

## Що тут повинно бути:
- Вихідний код веб-додатку відповідно до шарів FSD:
  - `app` (ініціалізація додатку, провайдери, глобальні стилі)
  - `pages` (сторінки додатку)
  - `widgets` (самостійні блоки інтерфейсу)
  - `features` (призначені для користувача сценарії та взаємодії)
  - `entities` (бізнес-сутності: користувач, сесія тощо)
  - `shared` (перевикористовувані компоненти, утиліти, UI-кіт, API клієнт)
- Інтеграція з бекендом через `web-api`.
- Конфігураційні файли збірки, лінтингу та пакетного менеджера.
