# Deploy

Ця директорія містить конфігурації, інструкції, скрипти та документацію щодо розгортання, інфраструктури та підтримки проєкту CosmoLost.

## Що тут повинно бути?
- **Docker Compose файли (для розробки, стейджингу та продакшну):** для розробки, стейджингу та продакшну
- **Конфігураційні файли веб-серверів та реверс-проксі:** для зовнішньої та внутрішньої мережі
