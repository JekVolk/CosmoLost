# Завдання для Дизайнера №1: Вебпортал CosmoLost (Three.js 3D Карта)

> **Для передачі**: Дизайнерці (Віолетта).  
> **Ціль**: Створити дизайн для веб-клієнта платформи CosmoLost.  
> **Дизайн-система**: **Chakra UI v3** (Строго БЕЗ Tailwind CSS!).  
> **Тематика**: Deep Space Sci-Fi (темний глибокий космос, зоряне небо, неонові акценти, чиста типографіка).  
> **Пов'язані файли**: [`04_DESIGN_SYSTEM_TOKENS_AND_ICONS.md`](./04_DESIGN_SYSTEM_TOKENS_AND_ICONS.md), [`03_PAGE_LAYOUTS_AND_MISSION_SPEC.md`](./03_PAGE_LAYOUTS_AND_MISSION_SPEC.md).

## 🎨 1. Готові Дизайн-Токени (Кольори, Відступи, Радіуси)

* **Колірна палітра**:
  * Фон сторінки (Space Black): `#0A0B10`
  * Напівпрозоре скло карток (Glass Card): `background: rgba(18, 20, 29, 0.75)`, `backdrop-filter: blur(12px)`, межа `1px solid rgba(255, 255, 255, 0.08)`
  * Неоновий акцент приладів (Telemetry Cyan): `#00F0FF` (світіння `box-shadow: 0 0 20px rgba(0, 240, 255, 0.35)`)
  * Золото Tier 1 відкриттів (Neon Amber): `#FFB800` (світіння `box-shadow: 0 0 25px rgba(255, 184, 0, 0.40)`)
  * Марсіанський рудий (Mars Rust): `#E2583E`
  * Місячний білий (Moon White): `#E0E6ED`
* **Сітка відступів**: строго 4px / 8px (`4, 8, 12, 16, 24, 32, 48 px`).
* **Радіуси скруглень**: `12px` (карточки), `8px` (інпути), `9999px` (бейджики).
* **Шрифти**: Заголовки — `Space Grotesk`, Текст — `Inter`, Телеметрія — `JetBrains Mono`.

## 📱 2. Перелік Екранів: Що саме потрібно намалювати

### Екран 1: Головна сторінка — 3D Інтерактивний Глобус (`/`)
1. **Header (Шапка)**:
   * Логотип `CosmoLost` з орбітальною іконкою.
   * Меню: `3D Карта`, `Каталог`, `Відео спільноти`, `Про проєкт`.
   * Бейдж швидкого виклику: `AI Gateway (MCP)`.
2. **Floating Planet Switcher (Перемикач планет по центру зверху)**:
   * Сегментований перемикач: `Місяць (Moon) 🌕` / `Марс (Mars) 🔴`.
3. **Floating Filter Bar (Плаваюча панель пошуку та фільтрів)**:
   * Рядок швидкого пошуку: `🔍 Пошук артефакту або кратера...`.
   * Чіпи фільтрації за 10 типами обладнання (`ROVER`, `LANDER`, `RETRO_REFLECTOR` тощо з іконками Lucide).
   * Чекбокс `⭐ Тільки Tier 1 (Кураторські 3D)`.
   * Лічильник: `Знайдено: 42 об'єкти`.
4. **Three.js Сцена (Центр екрана)**:
   * 3D глобус планети з тайлами NASA Treks.
   * Сяючі маркери точок артефактів.
   * Кластеризація $<500$ м: круглий бейдж `(3)`, що при наближенні плавно розкривається (Spiderfy).
   * Hover-тултіп при наведенні на точку: фото 80x80px + назва + локація + кнопка переходу.

---

### Екран 2: Висувна панель / Drawer артефакту (`/artifacts/:id`)
Відкривається плавно з правої частини екрана (ширина 480–540 px):
1. **Hero-блок**:
   * Бейдж статусу: `DORMANT 🔴` (знеструмлений) або `PASSIVE_ACTIVE 🟢` (лазерний відбивач).
   * Назва: `Opportunity Rover (MER-B)`.
   * Місія: `Mars Exploration Rover` (клікабельний лінк на сторінку місії).
   * Бейдж `Офіційне обладнання NASA ✅`.
2. **3D GLB Viewer (Інтерактивна 3D-модель)**:
   * Вікно 100% ширини $\times$ 300 px з 3D моделлю ровера/апарата.
   * Кнопки під моделлю: `Обертати`, `На весь екран`, `Скинути кут`.
3. **Бортовий журнал «Щоденник останнього Сола»**:
   * Блок у стилі термінала бортового комп'ютера з монологом en-US:
   * *«My clock stopped on Sol 5111. Darkness fell across Meridiani Planum...»*.
   * Дата втрати зв'язку та інженерна причина (глобальна пилова буря).
4. **Вкладки з деталями (Tabs)**:
   * **Вкладка «Наукові відкриття»**: акордеон приладів (Pancam, APXS) з дитячими поясненнями («Кульки чорниці») та фактами NASA PDS.
   * **Вкладка «Фотоархів NASA»**: сітка фотографій із каталожними кодами `PIA22521` та переглядом на весь екран.
   * **Вкладка «Маршрут та Телеметрія»**: графік накопиченого пробігу (одометрія) та показники батарей/пилу.

### Екран 3: Каталог артефактів списком (`/catalog`)
* Альтернативний табличний або сітковий режим для людей без 3D.
* Картки в 3 колонки: фото, назва, іконка типу обладнання, маса в кг, статус, місце посадки, кнопка `Детальніше`.

---

### Екран 4: Відеогалерея Спільноти (`/community`)
* Вітрина вертикальних роликів 9:16 (YouTube Shorts / TikTok плеєри).
* Під кожним відео: назва, нікнейм автора (`@SpaceGeek99`), обов'язковий блок цитованих першоджерел (PIA-коди та посилання на PDS).
* Кнопка у верхньому кутку: `+ Подати власне відео на модерацію`.
