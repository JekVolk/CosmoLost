# Робочий Пакет Дизайнера CosmoLost (00_DESIGNER_BRIEF_HANDOFF.md)

> **Кому**: Головній дизайнерці проєкту (Віолетта).  
> **Від кого**: Тімлід / Архітектор (Женя).  
> **Проєкт**: CosmoLost («Покинуті, але не забуті») — NASA Space Apps Challenge 2026.  
> **Дизайн-система**: **Chakra UI v3** (Строго БЕЗ Tailwind CSS!).  

---

## 👋 Привіт, Віолетто!

Ми підготували для тебе вичерпний покроковий пакет завдань, розписаний максимально конкретно та без «води». Тобі не доведеться вигадувати структуру екранів чи шукати іконки — усе розбито по поличках із точними розмірами, неоновими Sci-Fi ефектами та полями з бази даних.

Весь робочий пакет складається з **4 файлів у цій папці `design/`**:

---

### 📂 Файл 1: Дизайн Вебпорталу (3D Three.js Карта та Картки)
👉 **[`01_TASK_DESIGN_PORTAL_WEB.md`](./01_TASK_DESIGN_PORTAL_WEB.md)**
* **Що малювати**:
  1. **Головна сторінка з 3D глобусом Three.js**: перемикач планет `Місяць 🌕` / `Марс 🔴`, плаваюча панель фільтрів за типами апаратів, кластеризація точок $<500$ м (бейдж `(3)` з ефектом Spiderfy) та спливаючий hover-тултіп з фото.
  2. **Висувна картка артефакту (Drawer)**: інтерактивна 3D-модель `.glb` з NASA GitHub, атмосферний монолог «Щоденник останнього Сола» (en-US), вкладки наукових приладів та архівних фото NASA PIA.
  3. **Каталог списком**: альтернативна сітка карток для слабких ПК.
  4. **Відеогалерея спільноти**: вітрина 9:16 Shorts/TikTok з обов'язковим зазначенням першоджерел контенту.

---

### 📂 Файл 2: Дизайн Десктопної «Фабрики Контенту» (Tauri SMM Studio)
👉 **[`02_TASK_DESIGN_EDITOR_DESKTOP.md`](./02_TASK_DESIGN_EDITOR_DESKTOP.md)**
* **Що малювати**:
  1. **Спліт-вікно (дві панелі)**:
     * **Зліва**: нодовий граф конвеєра (`@xyflow/react`): вибір артефакта $\to$ рубрика (~40 секунд, поле `selection_reason`) $\to$ озвучка TTS $\to$ композитинг $\to$ публікація.
     * **Справа**: монітор прев'ю 9:16 із кнопкою перемикання **Мертвих зон (Safe Zones)**: верх 220px, низ 420px, право 150px.
  2. **Ефект Pillow-box**: красивий розмитий задній фон для архівних фото NASA $4:3$ або квадратних знімків замість обрізання.
  3. **Кастомізація PNGTuber аватара**: сітка 4 емоцій $\times$ 2 фази рота = **8 спрайтів** (Idle, Expert, Shock, Hype) під ліпсінк.
  4. **Модалка Smart Next Topic**: картка рекомендації наступного ролика з готовим сюжетним хуком (3с) та мостом між історіями.

---

### 📂 Файл 3: Детальна Анатомія та Wireframe Сторінки Місії (`/missions/:id`)
👉 **[`03_PAGE_LAYOUTS_AND_MISSION_SPEC.md`](./03_PAGE_LAYOUTS_AND_MISSION_SPEC.md)**
* **6 обов'язкових блоків зверху донизу**:
  1. **Hero-шапка**: назва експедиції, агентство `NASA`, каталожний код `NSSDC ID`, 4 плашки дат (старт, посадка, фінал, лічильник заліза).
  2. **Опис місії**: історія цілей польоту та плашка для школярів «Чому це важливо».
  3. **Маніфест залишеного заліза**: сітка карток усіх апаратів цієї місії з фото, координатами, статусом і кнопкою переходу до 3D.
  4. **Зведені наукові відкриття**: прилади з аналогіями для дітей та фактами PDS.
  5. **Відео спільноти про цю місію**: вертикальні ролики Shorts із цитуванням джерел.
  6. **Офіційні референси NASA**: лінк на NSSDCA та копірайт.

---

### 📂 Файл 4: Дизайн-Система, Токени та 10 Іконок NASA
👉 **[`04_DESIGN_SYSTEM_TOKENS_AND_ICONS.md`](./04_DESIGN_SYSTEM_TOKENS_AND_ICONS.md)**
* **Готові параметри для Figma та коду**:
  * **Сітка**: строго 4px / 8px (`4, 8, 12, 16, 24, 32, 48 px`).
  * **Кольори**: чорний космос `#0A0B10`, напівпрозоре скло `#12141D` (`backdrop-filter: blur(12px)`), неоновий ціан `#00F0FF`, золото `#FFB800`, марсіанський рудий `#E2583E`.
  * **Радіуси**: `12px` (картки), `8px` (інпути), `9999px` (бейджики).
  * **Іконковий пак Lucide для 10 типів обладнання**: готові піктограми для марсоходів, дронів, посадкових модулів, лазерних дзеркал і трубок зразків.
