# Завдання для Дизайнера №2: Десктопна «Фабрика Контенту» (Tauri SMM Studio)

> **Для передачі**: Дизайнерці (Віолетта).  
> **Ціль**: Створити дизайн для десктопного застосунку автоматизованого монтажу вірусних коротких відео (Shorts / TikTok / Reels) за даними NASA.  
> **Технічний стек**: **Tauri v2 + React 19 + Chakra UI v3 + `@xyflow/react` (React Flow)**.  
> **Принцип роботи**: **Local-First** (монтаж FFmpeg, TTS та збереження відбуваються локально на комп'ютері користувача).  

---

## 📐 1. SMM-Стандарти Відео та Мертві Зони (Safe Zones)

Відео рендериться суворо у вертикальному форматі **$1080 \times 1920$ px ($9:16$)**, середня тривалість — **~40 секунд**.

### Мертві зони інтерфейсу мобільних соцмереж:
1. **Верхня мертва зона**: **220 px** зверху (перекривається рядком пошуку соцмережі та назвою треку).
2. **Нижня мертва зона**: **420 px** знизу (перекривається нікнеймом, описом ролика та коментарями).
3. **Права мертва зона**: **150 px** праворуч (перекривається кнопками лайків, шерингу та звукової доріжки).
4. **Центральна безпечна зона**: тут розташовуються субтитри, 3D апарат та персонаж-диктор.

### Ефект Pillow-box для архівних фото 4:3:
Для історичних фотографій NASA системно генерується **естетичний розмитий задній фон** із самого знімка, а оригінал різко ставиться по центру без обрізання країв.

## 🖥️ 2. Перелік Екранів та Блоків Десктопного Додатка

У застосунку розробляється **двопанельне робоче вікно (Спліт-екран)** + 2 модалки:

```
+-----------------------------------------------------------------------------------+
|                        ВЕРХНІЙ ТУЛБАР (HEADER / ACTION BAR)                       |
+-------------------------------------------------+---------------------------------+
|                                                 |                                 |
|            ЛІВА ПАНЕЛЬ (60% ШИРИНИ):            |   ПРАВА ПАНЕЛЬ (40% ШИРИНИ):    |
|             НОДОВИЙ ГРАФ РОБОТИ                 |    ІНТЕРАКТИВНИЙ 9:16 ПЛЕЄР     |
|              (@xyflow/react)                    |     (SAFE ZONES PREVIEW)        |
|                                                 |                                 |
|  [ArtifactNode] -> [ScriptNode] -> [TTSNode]   |  +---------------------------+  |
|                          |                      |  |     Верхня зона 220px     |  |
|                          v                      |  |   [БЕЗПЕЧНА ЗОНА 9:16]    |  |
|              [CompositeNode] -> [PublishNode]   |  |   (3D / Фото + Субтитри)  |  |
|                                                 |  |    Нижня зона 420px       |  |
|                                                 |  +---------------------------+  |
|                                                 |  [Кнопка Рендер] [Експорт]      |
+-------------------------------------------------+---------------------------------+
```

### 1. Верхній Тулбар (Action Header)
* Назва проекту: наприклад `Opportunity_Sol_5111_Project`.
* Бейдж статусу: `DRAFT ⚪`, `RENDERING 🟡 (35%)`, `RENDERED 🟢`.
* Повзунок таймауту GPU (`render_timeout_sec`): вибір 30с, 40с дефолт, 90–120с для слабких відеокарт.
* Кнопки швидкої дії: `▶️ Змонтувати (FFmpeg)`, `🚀 Опублікувати / Експорт`.

---

### 2. Полотно Нодового Графа (Ліва панель — React Flow)
Складається з 5 з'єднаних карток-нод:
1. **`ArtifactSourceNode`**: вибір планети (Місяць/Марс), пошуковий селектор артефакту, міні-прев'ю обраного апарата.
2. **`ScriptTemplateNode`**:
   * Вибір рубрики: `Останній день на зв'язку (~40с)`, `Як це працює? (~35с)`, `Таємниці Місяця (~40с)`.
   * **Поле мотивації (`selection_reason`)**: поле вводу (від 10 до 500 символів), де автор пише, чому обрано саме цю тему.
   * Акордеон 4 слайдів: Хук (3.5с), B-roll факти (14с), Драма (16.5с), Фінал-петля (6с).
   * Кнопка: **`✨ Придумати тему для наступного відоса`** (Smart Next Topic).
3. **`AudioTTSNode`**: вибір мови (UK/EN), голос диктора, Jump-cut обрізка пауз, шкала RMS-амплітуди для ліпсингу.
4. **`VisualCompositeNode`**: чекбокс Pillow-box (розмитий фон), вибір аватара (дефолтний від Віолетти або кастомний), HUD телеметрія.
5. **`SocialPublishNode`**: селектори соцмереж (Shorts, Telegram, диск), 3-рядковий опис та Pin Comment.

---

### 3. Інтерактивний 9:16 Монітор Прев'ю (Права панель)
* Вертикальний монітор смартфона з масштабуванням.
* Перемикач `Показати безпечні зони`: накладає червону напівпрозору сітку на мертві зони 220px, 420px, 150px.
* Кнопки під монітором:
  * `📋 Скопіювати опис та хештеги`
  * `💬 Скопіювати закріплений коментар (Pin Comment)`
  * `📂 Відкрити папку з готовим відео` (виклик системного Explorer / Finder).

---

### 4. Модалка кастомізації PNGTuber аватара
* Сітка 4 емоцій $\times$ 2 фази рота = **8 спрайтів**:
  1. `Idle` (закритий / відкритий рот)
  2. `Expert` (закритий / відкритий рот)
  3. `Shock` (закритий / відкритий рот)
  4. `Hype` (закритий / відкритий рот)
* Кнопка завантаження свого PNG для кожної клітинки.
* Повзунок тесту мікрофона (рот аватара відкривається в такт голосу).

---

### 5. Модалка Smart Next Topic Engine («Придумати наступну тему»)
* Картка наступного артефакта з бази даних:
  * Рекомендований апарат (наприклад, *Spirit Rover*).
  * Сюжетний міст (Narrative Bridge) між попереднім і новим роликом.
  * Сюжетний хук на 3 секунди.
  * Дискусійне питання для закріпленого коментаря.
* Кнопка: `✅ Застосувати та створити ролик`.
