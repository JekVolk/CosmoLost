## 7. Загальні стани компонентів

Для інтерактивних компонентів передбачити такі стани:

- Default — звичайний стан.
- Hover — наведення курсора.
- Active — натискання.
- Focus — фокус клавіатури.
- Disabled — недоступний стан.
- Loading — завантаження.
- Error — помилка.
- Selected — вибраний елемент.

## 8. Вимоги до повторного використання

- Використовувати єдині стилі кнопок, бейджів, карток та полів.
- Повторно використовувати компоненти на різних сторінках.
- Для Місяця та Марса зберігати однакову структуру інтерфейсу.
- Змінювати акцентну палітру залежно від вибраної планети.
- Не створювати окремі компоненти для однакових елементів без необхідності.
- Компоненти 3D-сцени та маркерів реалізовувати засобами Three.js, а не Chakra UI.
