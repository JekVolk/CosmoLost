# Список сторінок проєкту

## Загальна концепція

**Назва:** Lost Equipment Explorer

**Призначення:** інтерактивна платформа для дослідження покинутого, загубленого та залишеного космічного обладнання на Місяці та Марсі.

Користувач може обертати 3D-модель планети, переглядати місця розташування об'єктів, знаходити інформацію про космічні місії та переглядати детальні картки артефактів.

Основний візуальний стиль — CosmoDark, темна космічна тема з неоновими маркерами та напівпрозорими панелями.

---

## [UC-DES-01] Головний екран 3D-мапи космосу

**Назва сторінки:** Головна сторінка / 3D Map

**Призначення:**
Надати користувачу можливість досліджувати поверхню Місяця та Марса, знаходити покинуте обладнання та переглядати коротку інформацію про нього.

**Основні блоки:**

1. Верхня панель навігації:
   - Назва та логотип проєкту.
   - Перемикач планет Moon / Mars.
   - Слайдер років 1960–2026.
   - Кнопка пошуку.
   - Кнопка фільтрів.
   - Кнопка меню.

2. Центральна 3D-сцена:
   - Темне зоряне тло.
   - 3D-сфера Місяця або Марса.
   - Можливість обертання та масштабування за допомогою OrbitControls.
   - Маркери розташування артефактів.
   - Візуальні ефекти світіння маркерів.
   - Підказки при наведенні на маркери.

3. Ліва панель фільтрів:
   - Тип обладнання.
   - Статус об'єкта.
   - Космічна місія.
   - Можливість очищення фільтрів.

4. Hover Tooltip:
   - Назва об'єкта.
   - Назва місії.
   - Мініатюра фотографії.
   - Координати.
   - Коротка інформація.

5. Панель керування 3D-сценою:
   - Обертання.
   - Масштабування.
   - Скидання положення камери.

6. Нижня інформаційна панель:
   - Кількість знайдених об'єктів.
   - Дата останнього оновлення.
   - Кнопка поширення.

**Візуальні стани:**
- Empty — об'єкти не знайдені або відсутні.
- Loading — завантаження карти та маркерів із використанням Skeleton.
- Success — карта та об'єкти успішно відображені.
- Error — помилка завантаження з можливістю повторити запит.

**Адаптивність:**
- Desktop: 1920 × 1080 px.
- Mobile: 390 × 844 px.

## [UC-DES-02] Кластеризація точок (Spiderfying)

**Назва сторінки / стану:** Cluster View

**Призначення:**
Забезпечити зручний перегляд груп об'єктів, розташованих близько один до одного.

**Основні блоки:**
- Круглий числовий бейдж із кількістю об'єктів.
- Назва місця або місії.
- Лінії зв'язку між кластером та окремими маркерами.
- Окремі значки для кожного типу обладнання.

**Візуальні стани:**

1. Згорнутий кластер:
   - Круглий бейдж із числом.
   - Приклад: Apollo 11 Site (5).

2. Розгорнутий кластер:
   - Маркери розташовані радіально.
   - Між ними та початковим центром відображаються лінії.
   - Кожен маркер має власний значок обладнання.

3. Hover:
   - При наведенні на окрему точку показується коротка підказка.

4. Selected:
   - Вибраний об'єкт виділяється світінням.
   - Відкривається інформаційна картка.

**Вхідні приклади:**
- Apollo 11 Site — 5–8 об'єктів.
- Perseverance Three Forks — 5–8 об'єктів.

**Примітка:** кластеризація є інтерактивним станом головної 3D-мапи, а не окремою повноцінною сторінкою.

## [UC-DES-03] Детальна сторінка артефакту

**Назва сторінки:** Artifact Details

**Маршрут:** /artifacts/:id/

**Призначення:**
Надати користувачу повну інформацію про вибраний космічний артефакт.

**Основні блоки:**

1. Верхній блок:
   - Назва артефакту.
   - Офіційний код NSSDCA.
   - Бейдж планети.
   - Статус об'єкта.
   - Кнопка повернення до карти.

2. 3D Viewer:
   - Перегляд моделі артефакту у форматі GLB.
   - Обертання моделі.
   - Масштабування.
   - Скидання положення камери.

3. Основна інформація:
   - Назва космічної місії.
   - Дата запуску або посадки.
   - Координати об'єкта.
   - Тип обладнання.
   - Статус.
   - Опис призначення.

4. Медіагалерея:
   - Архівні фотографії формату 4:3.
   - Рекомендований розмір зображення 800 × 600 px.
   - Розмитий фон на основі відповідної фотографії.
   - Перемикання між фотографіями.

5. Монолог від першої особи:
   - Художня розповідь від імені артефакту.
   - Візуально відокремлений текстовий блок.

6. Наукова спадщина:
   - Значення об'єкта для дослідження космосу.
   - Його внесок у наукові місії.

7. Джерела NASA:
   - Посилання на офіційні матеріали.
   - Посилання на архівні фотографії.
   - Бібліографічна інформація.

8. Блок цитування:
   - Текст бібліографічного посилання.
   - Кнопка копіювання.

**Візуальні стани:**
- Loading — завантаження GLB-моделі та інформації.
- Success — повна картка артефакту.
- Model Error — помилка завантаження 3D-моделі.
- Data Error — помилка отримання інформації.

## [UC-DES-04] PNGTuber Аватар та Safe Zones

**Назва сторінки:** PNGTuber Studio

**Призначення:**
Підготувати вертикальну композицію з аватаром та субтитрами для відео про космічні артефакти.

**Розмір полотна:** 1080 × 1920 px (9:16).

**Основні блоки:**

1. Полотно попереднього перегляду відео.
2. Аватар Віолетти.
3. Панель вибору виразу обличчя.
4. Панель субтитрів.
5. Візуальні межі Safe Zones.
6. Панель керування розташуванням елементів.

**Вирази аватара:**
- Idle — спокійний вираз.
- Expert — експертний вираз в окулярах.
- Shock — здивування або шок.
- Hype — захоплення відкриттям.

**Вимоги до спрайтів:**
- 8 файлів PNG.
- Розмір кожного файлу 512 × 512 px.
- Прозорий фон Alpha PNG.
- Для кожного виразу дві фази рота: закритий та відкритий.

**Розташування:**
- Верхня мертва зона: 220 px.
- Нижня мертва зона: 420 px.
- Права мертва зона: 150 px.
- Аватар: Y = 1500 px.
- Субтитри: у безпечній області між Y = 300 px та Y = 1400 px.

## [UC-DES-05] Діалог публікації та нативна папка

**Назва компонента:** Publication Dialog

**Призначення:**
Надати можливість підготувати SEO-опис та матеріали для поширення відео на різних платформах.

**Основні блоки:**

1. Заголовок діалогу.
2. Вибір платформ:
   - YouTube Shorts.
   - Telegram.
   - TikTok (відкриття папки для публікації).
3. Попередній перегляд SEO-опису:
   - Опис із трьох рядків.
   - Ключові слова.
   - Хештеги.
   - Підсвічування відповідних фрагментів.
4. Блок Pin Comment:
   - Текст закріпленого коментаря.
   - Кнопка копіювання.
5. Панель дій:
   - Копіювати SEO-пакет.
   - Відкрити папку.
   - Закрити діалог.

**Візуальні стани:**
- Default — початковий стан.
- Selected — вибрані платформи.
- Copied — матеріали скопійовані.
- Folder Opened — папка відкрита.
- Error — помилка виконання дії.

**Текст успішного повідомлення:**

«Папку відкрито, SEO-пакет у буфері обміну!»

## Загальні вимоги до дизайну

- Єдина темна космічна тема CosmoDark.
- Узгоджені компоненти для всіх сторінок.
- Висока контрастність тексту відповідно до WCAG AAA, де це можливо.
- Не перевантажувати 3D-сцену декоративними елементами.
- Зберігати чітку візуальну ієрархію.
- Використовувати однакові правила відступів, скруглень та типографіки.
- Інтерактивні стани мають бути візуально відмінними.
- Основні екрани повинні мати Desktop та Mobile макети.
