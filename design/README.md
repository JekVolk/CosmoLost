# Design

Ця директорія відповідає за дизайн-систему, UI/UX ресурси та візуальні специфікації проєкту **CosmoLost**.

## Що тут повинно бути:
- **Дизайн для web-client:** Макети, UI-компоненти, стилі та UX-сценарії для веб-інтерфейсу.
- **Дизайн для desktop-client:** Макети та специфікації інтерфейсу для десктопного застосунку.
- **Скіли та ресурси:** Активи, іконки, кольорові палітри, типографіка, дизайн-токени та специфікації компонентів (дизайн-скіли).
- **Гіт коміт (Git Commit гайдлайни):** Регламент та правила фіксації змін у репозиторії для дизайнерських файлів та ресурсів.
