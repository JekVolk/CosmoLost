## 🛠️ Вимоги та Стандарти:
* **Дизайн-система коду**: **Chakra UI v3** (Строго БЕЗ Tailwind CSS!).
* **Типографіка**: `Space Grotesk` (заголовки), `Inter` (основний текст), `JetBrains Mono` (телеметрія).
* **Стилістика**: Deep Space Sci-Fi (глибокий чорний простір, напівпрозоре скло, неонові акценти).
