## 1. Реєстр Ендпоінтів та SMM Логіка

- [x] **`GET /api/v1/editor/templates/`**:
  - [x] Повертає статичний реєстр готових SMM-рубрик:
    - `last-sol-drama` («Останній подих ровера: драма кінця місії»).
    - `dictionary-explain` («Наука для чайників: простими словами про космос»).
    - `lunar-secrets` («Забуті таємниці місячних перегонів»).
  - [x] Кожна рубрика містить структуру 4 слайдів: `Hook`, `B-Roll`, `Drama Peak`, `Loop CTA`.
  - [x] Включено розмітку Safe Zones та цільовий хронометраж ~40 секунд.
- [x] **`GET /api/v1/editor/templates/<pk>/`**:
  - [x] Повертає детальну конфігурацію рубрики; при неіснуючому `pk` повертає HTTP 404.
- [x] **`GET /api/v1/editor/artifacts/<pk>/assets/`**:
  - [x] Формує повний пакет активів для монтажного столу:
    - `script_text_en`: оригінальний монолог англійською мовою.
    - `script_text_uk`: адаптований український текст диктора.
    - `seo_caption_3lines`: 3-рядковий опис для опису ролика з обов'язковим `#cosmolost`.
    - `discussion_pin_question`: інтригуюче питання для першого коментаря із знаком `?` у кінці.
    - `broll_photo_urls`: масив прямих посилань на фотографії високої роздільності.
    - `model_3d_url`: прямий лінк на 3D файл `.glb`.
  - [x] Запобігає крашу, якщо фотографії відсутні (використовує fallback-зображення).
- [x] **`POST /api/v1/editor/recommend-next-topic/`**:
  - [x] Графовий рушій серійності контенту («Smart Next Topic Engine»).
  - [x] Приймає: `current_artifact_id`, `rubric_id`, `selection_reason`.
  - [x] Алгоритм підбору:
    1. Пошук іншого обладнання тієї ж самої місії (Mission Sibling).
    2. Пошук спорідненого обладнання того ж самого небесного тіла (Body Sibling).
    3. Детермінований fallback на інший артефакт бази.
  - [x] Генерує перехідний місток (Narrative Bridge) та вірусний хук для наступного ролика.
  - [x] Валідація: вимагає `selection_reason` довжиною не менше 10 символів; неіснуючий артефакт повертає HTTP 400.
- [x] **Сумісність аліасів**:
  - [x] Повний дублюючий контур `/api/desktop/` повертає ідентичні структури даних.
