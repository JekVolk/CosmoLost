## 1. Реєстр Інструментів FastMCP (10 Tools)

- [x] **1. `search_artifacts`**:
  - [x] Пошук по назві, локації, науковому внеску.
  - [x] Фільтрація: `celestial_body`, `artifact_type`, `operational_status`, `is_featured`.
  - [x] Пагінація (`limit`, `offset`) з захистом від переповнення ($limit \le 100$).
  - [x] Нормалізація координат за IAU 2000.
- [x] **2. `get_artifact_details`**:
  - [x] Повний паспорт артефакту за унікальним `artifact_id`.
  - [x] Координати, маса, дата останнього контакту, причина зупинки, монолог першої особи.
- [x] **3. `get_mission_manifest`**:
  - [x] Повний список усього обладнання, залишеного конкретною місією (наприклад, `apollo-11`).
- [x] **4. `get_last_sol_chronology`**:
  - [x] Останній пакет телеметрії (заряд батареї Wh, оптична товщина пилу Tau, нахил).
  - [x] Розрахунок приблизної земної дати за марсіанським солом (`sol_to_earth_date`).
- [x] **5. `get_science_discoveries`**:
  - [x] Перелік наукових відкриттів апарату з назвами приладів та версією для дітей.
- [x] **6. `get_verified_citations`**:
  - [x] Наукові першоджерела: NSSDCA ID, NASA Planetary Data System (PDS) ноди, канонічні URL.
- [x] **7. `get_3d_and_media_assets`**:
  - [x] Прямі лінки на `.glb` файли 3D моделей з NASA CDN та архівні фото PIA.
- [x] **8. `list_active_passive_artifacts`**:
  - [x] Спеціалізована вибірка пасивних реліквій, що досі працюють без живлення (лазерні куточкові відбивачі Apollo 11, 14, 15, Луноход-1/2).
- [x] **9. `list_celestial_bodies` (Бонусний інструмент)**:
  - [x] Каталог планет із фізичними параметрами та кількістю обладнання.
- [x] **10. `list_missions` (Бонусний інструмент)**:
  - [x] Каталог програм польотів із фільтрацією за космічною агенцією.

## 2. Протоколи та Захист від Атак

- [x] **Режими запуску**:
  - [x] **Stdio**: пряме підключення до Claude Desktop та Cursor через конфігурацію запуску Python.
  - [x] **SSE (Server-Sent Events)**: мережевий режим на порті 8001 для мережевих ШІ-агентів.
  - [x] Конфігурація Nginx: `proxy_buffering off` та `proxy_read_timeout 86400s`.
- [x] **Безпекова санітизація**:
  - [x] Відсікання нуль-байтів (`\x00`).
  - [x] Блокування рядкових бомб (обрізка запитів до 10 000 символів).
  - [x] Захист від Path Traversal у слагах та ідентифікаторах.
  - [x] Запобігання JSON серіалізаційним крашам через `NaN` / `Infinity` флоати (`safe_float`).
