# 📋 Матриця Тестування Платформи CosmoLost для Клієнта (Client Master Testing Matrix)
## Комплексна матриця верифікації функціоналу, критеріїв приймання та статусів готовності

> **Проєкт**: CosmoLost («Abandoned, but not forgotten»)  
> **Версія платформи**: v0.6.1 (Batch 1 Audit)  
> **Призначення документа**: Офіційна клієнтська матриця тестування для верифікації вимог, обсягу робіт, поточного статусу розробки та критеріїв приймального тестування (UAT).  
> **Нормативна база**: `business/spec/` (PRD, C4, OpenAPI, Domain Entities, Operations, Validations, QA Acceptance Cases).

---

## 1. Пояснення структури та статусів матриці

Кожен пункт матриці містить:
1. **ID Модуля / Мікросервісу**: Унікальний ідентифікатор компонента в архітектурі.
2. **Функціонал та компонент**: Конкретна можливість системи.
3. **Референс специфікації**: Посилання на бізнес-документи (`FEAT-*`, `UC-*`, `OP-*`, `FIELD-*`, `QA-*`).
4. **Що повинно бути за функціонал (Вимога клієнта)**: Опис очікуваної бізнес-поведінки.
5. **Поточний статус (Batch 1)**:
   - `ГОТОВО (100%)` — повністю реалізовано у коді та покрито автоматизованими тестами.
   - `ЧАСТКОВО (~50-80%)` — базовий функціонал працює, але вимагає фінальної інтеграції або оптимізації у Batch 2.
   - `ПЕРЕНЕСЕНО НА BATCH 2` — заплановано до реалізації в другій черзі згідно з архітектурним планом.
6. **Рівень та тип тестування**: Unit (модульне), Integration (інтеграційне), E2E (наскрізне), Visual 3D, Audio/Video, Security, Performance.
7. **Автоматизоване покриття**: Наявність тестів у Pytest (92 тести) або Vitest (24 сьюти).
8. **Критерії приймання клієнтом**: Точні умови, за яких клієнт ставить підпис про прийом функціоналу.

## 4. Інструкція з Приймального Тестування Клієнтом (UAT Walkthrough)

Клієнт може особисто верифікувати кожен із ключових блоків системи за наступними кроками:

### Крок 1. Перевірка Бекенду та Бази Даних
1. Відкрити термінал у папці `backend/` та виконати:
   ```powershell
   uv run pytest
   ```
2. **Очікуваний результат**: Усі 92 тести проходять успішно (`92 passed in ~9-11s`).

### Крок 2. Перевірка ШІ-Шлюзу FastMCP
1. Запустити сервер FastMCP у консолі:
   ```powershell
   uv run python mcp/server.py --transport sse --port 8001
   ```
2. Звернутися до ендпоінту `http://localhost:8001/tools/` або використати Cursor/Claude Desktop.
3. **Очікуваний результат**: Доступні 10 верифікованих інструментів, що повертають факти NASA з посиланнями на першоджерела.

### Крок 3. Перевірка Десктопної «Фабрики Контенту»
1. Відкрити термінал у папці `desktop-client/` та виконати запуск тестів:
   ```powershell
   pnpm test
   ```
2. **Очікуваний результат**: Усі 24 сьюти тестів Vitest проходять успішно, включаючи реальний E2E тест MCP-сервера.

### Крок 4. Перевірка Вебпорталу 3D
1. Запустити веб-клієнт у режимі розробки:
   ```powershell
   cd web-client; npm run dev
   ```
2. Відкрити в браузері `http://localhost:5173`.
3. Покрутити 3D-сферу мишкою, перемкнути планету на Марс, навести курсор на маркер Curiosity, переглянути тултіп та перейти у каталог.
