# Testing

Ця директорія призначена для тестування компонентів проєкту **CosmoLost** із застосуванням автоматизації та штучного інтелекту (ШІ).

## Що тут повинно бути:
- **ШІ-тестування адмінки:** Автоматизовані сценарії та ШІ-агенти для перевірки адміністративної панелі.
- **ШІ-тестування веб-сайту:** Тести для перевірки користувацького інтерфейсу та функціоналу веб-клієнта.
- **ШІ-тестування застосунку (приложухи):** Сценарії тестування десктопного клієнта (`desktop-client`).
- **ШІ-тестування двох MCP:** Тестування, валідація та верифікація для 2-х серверів/інтеграцій MCP (Model Context Protocol).
- **Загальні тести:** Юніт-тести, інтеграційні та E2E тести, звіти про покриття.
